# 🧾 审计附注自动搬运系统

一个把 Word 附注里的表格数据、和 Excel 里的本年数据对起来，自动换数、再写回 Word 并回读核对的本地小工具。全程在你自己的电脑上跑，数据不出门。

---

## 🎯 它到底解决什么问题

做审计报告时，附注里有几十张表：货币资金、应收账款、存货、固定资产……每张表的数字都要从客户给的 Excel 里抄过来。

人工抄有三个麻烦：

1. 慢。几十张表、上千个格子。
2. 容易错。抄串行、抄错列很常见。
3. 改完还得核对一遍，又是一轮。

这个工具干的事就是：把 Word 里的表读出来 → 认清楚每一格是什么意思 → 到 Excel 里找意思相同的那一格 → 把数字换过去 → 写回 Word → 再把 Word 读一遍，逐格核对有没有写对。

---

## 👥 谁适合用

- 做审计底稿、每年要把上一年附注改成今年数据的人。
- 手上有一份排版好的上一年 Word 附注，和一份今年的数据表。
- 不想把客户资料传到网上的人。

---

## 🧩 用之前要准备三样东西

| 要准备的东西 | 长什么样 | 说明 |
|---|---|---|
| 上一年的 Word 附注 | 一个 Word 文档，表格已经排好版 | 程序只读它，不改原件 |
| 今年的数据表 | 一个 Excel 文件，里面有一张按附注顺序堆着许多小表的工作表 | 程序只读它，不改原件 |
| 金标准文件 | 一个后缀为 jsonl 的文本文件，里面是各种附注说法的标准写法 | 由项目方提供，同样只读 |

三样东西都放在电脑里就行，不需要联网上传。

## 🚀 怎么启动

1. 确认电脑装好了两样东西：
   - 🐍 Python 运行环境（3.14 或更高）
   - 🧱 微软的 .NET 运行环境（Word 读写要靠它）
2. 打开项目文件夹，双击 **启动服务.pyw**。
   - 会弹出一个小黑窗，别关它，关了服务就停了。
3. 浏览器打开 **127.0.0.1:8765**。
   - 如果这个门牌号被别的程序占了，程序会自动往后顺延一个，具体看小黑窗里显示的地址。
4. 用完直接关掉小黑窗即可。

## 🖥 界面上有四个区，逐个说清楚

### ① 任务区（平时最常用）

1. 点「Word 附注」右边的**选择**，挑那份 Word 文档。
2. 点「数据表」右边的**选择**，挑那份 Excel。
3. 点「金标准」右边的**选择**，挑那个 jsonl 文件。
4. 点**开始**。中途断了、或者答复完接着跑，点**继续上次任务**——它沿用原来的任务文件夹，不会新建一个、也不会重跑已经做完的部分。

下面的进度区会一直刷新，告诉你三件事：

- 现在做到哪一步（提取／分科目／分表／逐表精读／配对／搬运／写回／回读）
- 已经做完了多少
- 有没有卡住，卡在哪份材料上（这一条见下面「待答复」）

中途想停，点**中断**。程序会把当前这张表做完再停，不会留下半张表。

### ② 结果区

点**刷新结果**，先看到一段摘要：对应了多少条、清尾多少条、回读差异多少条，以及产物文件的完整路径。

再往下是三份清单：

- **对应清单**：哪些格子对上了，哪些没对上，没对上的原因是什么。可以用下拉框按原因筛选，比如只看「仅A侧有」。
- **问题清单**：读不到值、公式没存结果、标题改不了之类的情况。
- **回读差异**：写回 Word 之后重新读出来的值，和预期不一致的格子。这一栏是空的，才说明写对了。

点**打开产物目录**，直接弹出那个任务文件夹，不用自己去翻。

### ③ 设置区

这里填的是「让机器帮忙认表」时要用的服务地址、密钥、模型名。

- 填好点**保存**。密钥不会明文存在硬盘上，用的是 Windows 自带的加密功能。
- 点**测试连通**可以看服务通不通。只有真正返回成功才算连通；密钥不对、地址写错、服务端报错，都会如实说是什么问题，不会含糊地说「通了」。
- 如果不打算让机器帮忙认表，这一区可以完全不填，见下面「待答复」。

### ④ 人工回写区

适合这种场景：你自己在 Excel 里手工改了几个数，想直接把改动写回 Word。

1. 选「带连接 Word」（程序第一次提取时生成的那个文件）。
2. 选你改好并保存过的 Excel。
3. 如果增删过行，再把「基准表 A」选上，程序会先算清楚你在哪张表里增删了几行。
4. 点**回写 Word 新副本**。

## 🔍 后台到底在做什么（按顺序）

1. **📤 提取**：把 Word 里每一张表抠出来，放进一个 Excel 暂存，同时记下每张表前面那句话（标题）、单位和所在章节。
2. **🗂 第一遍：分科目**：整份文件看一遍，只判断「这一段属于哪个科目」。是表、但标准清单里没有对应科目的，写明「无对应科目：原标题」，照抄原文，便于人工一眼认出是哪张表。
3. **📑 第二遍：分表**：在科目里再切一次，判断哪几行是一张表，并给每张表起标准名称。同一张表被分页拆成两截的，要归到同一张业务表里；分不清是续表还是两张同名表的，停下交人工。
4. **🔬 第三遍：逐表精读**：一张表一张表地看，认清哪几列是数据、哪几行是明细、表头有几层、单位是什么，给每个数据格挑标准编号，并标上「同一个编号里排第几」和「这一格是期初、期末还是本期」。
5. **🔗 配对**：两侧先按「科目＋表名」认成同一张表，再按「编号（＋第几项）（＋期间）」一格一格对上。名字不参与判断，它是内容。
6. **📦 搬运**：把 Excel 那一侧的数字和名称一起搬过去。同一行里任何一格对不上，这一行整体不动——不允许「名字换了、数没换」。Excel 少一项就把尾部清空，多一项就停下请人加行或加列。
7. **✍️ 写回**：以提取出来的那份表为底稿，只改需要改的格子，样式、数字格式、表格区域名都保留，另存一份新 Word；表前的日期标题按该表原句替换。
8. **🔁 回读**：把新 Word 重新读一遍，逐格比对。差一格就判「回读不一致」，不会显示完成。

> 为什么中间要绕一圈 Excel？因为 Word 里改数字容易把排版弄坏，先在一份和 Word 表格一一对应的 Excel 上改，再由专门的写回程序一次性写进 Word，安全得多。

## ✋ 「待答复」是什么，遇到怎么办

这里的「三遍识别」既可以自动调模型跑，也可以由人逐份回答。没配模型（或你希望自己看）时，程序会把每一份要看的材料整理好，放在运行目录的 **调用留证** 文件夹里。

你会看到这样的文件夹：

- A_第一遍 —— 整份文件分科目
- A_第二遍 —— 在科目里分表
- A_表001、A_表002 …… —— 每张表一份

每个文件夹里有两个文件：**材料.txt**（要看的内容）和 **指令.txt**（要按什么格式回答）。

做法是：看材料，按格式写出答案，存成同目录下的 **答复.txt**，然后回到网页点**继续上次任务**。程序会接着往下走，已经答过的不再问。

进度区里那一行「卡在材料：……」就是在告诉你：还差哪几份没答。

---

## ⏸ 做到一半断了怎么办

不用从头来。

- 每一份材料答完就落盘，程序会记住做到哪儿。
- 点**继续上次任务**，沿用原来那个任务文件夹，从断的地方继续，不会新建目录、也不会重跑已完成的部分。
- 某张表想重做，把那个文件夹里的答复删掉，重新答一遍即可。

## 🛑 哪些情况程序会停下来交给人

程序不猜。碰到下面这些，它会明确报错并把情况写进清单，让你人工处理：

- 某个格子挂不上标准编号（认不出它是什么）。
- 增删的行落在所有表格区域之外，或者横跨两张表。
- 一次改动里既有增行又有删行，或者有两处以上互不相连的增删。
- 列数或列位置变了（本期明确不支持自动加列删列）。
- 表格的合并结构变了。
- 某一格的值读不出来，或者公式没有保存计算结果。
- Excel 比 Word 多出一项，装不下，需要先加行或加列。
- 整表口径对不上：币种、金额单位不一致，或者一边是期末余额、一边是本期发生额。
- 表前日期标题找不到唯一原句，改不了——这张表一个数都不换，避免出现「旧标题配新数」。
- 回读发现差异——步骤会停在「回读不一致」，不会假装完成。

## 📁 跑完之后，运行目录里有什么

每跑一次任务，程序会在 运行 文件夹里新建一个以时间命名的任务文件夹。里面常见这些文件：

| 文件 | 是什么 |
|---|---|
| 表A.xlsx | 从 Word 抠出来的表，一格对一格，带表格区域名 |
| 带连接Word.docx | 和上面那份表一一对应的 Word 副本，写回时要用 |
| 上下文.json | 每张表的位置、标题、所在章节 |
| 科目划分_A.jsonl、科目划分_B.jsonl | 第一步的结论：哪些行属于哪个科目 |
| 结构清单.jsonl | 每张表的结构：几列、几行、每行每列是什么角色 |
| A合集.jsonl、B合集.jsonl | 逐格清单：位置、科目、表名、行列路径、标准编号、原值 |
| 对应清单.jsonl | 两侧配对结果与原因 |
| 问题清单.jsonl | 需要人看的格子 |
| 更新后附注表格.xlsx | 换完数的表 |
| Word新副本.docx | 写回后的成品 |
| 回读记录.jsonl | 逐格核对差异，空文件表示完全一致 |
| 接续索引.json | 做到哪一步了，断了从这里接 |
| 调用留证 | 每份材料的原件与答复，便于复查 |

## 🔐 数据安全须知

- 三份原件全程只读，程序不会改动。测试里有专门一条用例，比对原件前后的指纹。
- 运行目录里装的是真实客户数据，**不要**把这个文件夹提交到网上，也不要用网盘同步。
- 设置区填的密钥用 Windows 自带的加密存本机，不会以明文落盘，也不会在接口里回传。
- **启用外部模型服务时，识别材料会发送到你所填的那个地址。** 发送的内容包括该表的表格原文、表前上下文、以及这张表的候选槽位清单（编号和名称），不包含其他表、也不包含你的密钥以外的配置。
- 程序本身不往任何固定服务器上传数据。除了你自己填的那个地址，没有别的外发通道。不想让数据离开本机，就别填设置区，改用人来答「待答复」。

## ❓ 常见问题

**双击了没反应？**
多半是没装 Python，或者装的位置不在系统能找到的地方。先确认 Python 能正常用。
另外，双击启动没有黑窗，出了错也看不见。去 运行\启动日志.txt 看最后一行，启动成功会写明实际地址，失败会写明原因；服务自己运行的详细记录在 运行\服务日志.txt，里面会写每次启动、访问和报错。

**网页打不开？**
看 运行\启动日志.txt 里记的实际地址和门牌号。默认 8765，被占用了会自动往后顺延，地址以日志里那一行为准。

**选择文件时没弹窗？**
弹窗可能跑到别的窗口后面了，看一下任务栏。

**进度一直不动？**
这一版逐表精读要靠人答，材料没答完就不会往下走。看进度区「卡在材料」那一行。

**结果里一大堆「仅 A 侧有」「仅 B 侧有」？**
说明两侧没挂到同一个标准编号上。先检查分科目、分表这两步的结论对不对，再看逐表精读里给的编号是不是从候选里挑的。

**数字搬过去变成文本了？**
不该发生。搬运时按原类型写，数字是数字、百分比还是百分比。真遇到就记下来，连同运行目录一起反馈。
