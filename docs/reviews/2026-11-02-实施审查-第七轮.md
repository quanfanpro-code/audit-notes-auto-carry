## 一、修的是什么

上一轮让完整性按格核对例外，但仍然把「不搬」当成“这一格已经交代”。于是 D 列没进列清单、只把 `D2:D3` 标成“不搬、交人工”时，这一项既没有占位记录、也没有被算成漏列：B 判完整、名单只有两项，A 第三项按“B 无此项”清空。问题清单里同时出现“交人工”和“已清空”，自相矛盾。

改法：**「不搬」不能替漏列的格作证。**

- 「合并」例外说明这些格是从属格、本来就不该单独铺，可以算交代；
- 「不搬」只说明这一格不交程序。它没有进列清单，就没有形成可计数的失败占位，拿它证明整列“已交代”，等于把识别失败读成“B 没有这一项”——所以不算交代。
- 结果：D 列记漏列 → 判不完整 → 禁止清尾 → A 第三项保留，交人工补齐。

同时把漏列问题写清楚：问题清单那条记录除了 `列: ["D"]`，还带 `行: {"D": [2, 3]}`（结构清单里另存 `漏列格`）。

| 用例 | 断言 |

| `test_第5轮_只有不搬例外不能证明列已交代` | 逐行=false、漏列=["D"]、问题里 列 与 行 都在 |
| `test_第5轮_只有不搬例外时A第三项保留` | A 第三项 `仅A侧有`，变更里不含它的名称和金额 |
