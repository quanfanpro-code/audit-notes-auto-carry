# 绿色软件打包需求

用户已确认：桌面一个完整文件夹，双击exe运行；Word和Excel使用本机安装版本，其余依赖和程序数据随软件放在同一目录。基线为独立复核通过的4cb972a。本轮沿用现有GUI和业务方案，只补交付、路径与启动适配，用户已授权直接制作和真实文件验收。

- Windows x64目录式软件，带Python、第三方库、.NET桌面运行时、Word桥接、固定版WebView2及既有前端成品，不要求安装Python、Node或额外运行时。
- 配置、识别记录、任务、成果、日志、缓存、临时文件及自动备份都在软件目录内。A/B原件可以在外部，仍只读。人工另存和记录存储不得写到包外。
- 默认金标准随包；不携带测试配置、模型密钥、历史验收任务。当前仓库没有待迁移的模型配置、界面设置或正式识别记录。
- 不改财务语义、三遍识别、配对、金额搬运、公式分类或复用解释规则。
- 程序依然使用既有模型连接或人工答复模式；免安装不等于自带离线识别模型。

## 验收

1. 在不含本机Python、Node和dotnet安装路径的进程环境中，从桌面exe启动；核验加载的WebView2和.NET来自包内。
2. 四种Word/Excel组合从打包程序入口执行，重开真实成品检查名单、金额、公式和原件哈希。
3. Excel独立工作进程从包内exe运行，不重复打开主窗口；Word桥接使用随包运行时。
4. 设置保存、识别记录、日志、临时文件和备份均在包内；包外写入请求被明确拒绝。
5. 换工作目录启动仍正常；复制到另一个中文目录后可启动、使用默认资料并创建新任务。既有历史中外部输入的绝对路径不擅自改写。
6. 完成任务拒绝重跑、正常关闭释放端口；保留实际日志和版本清单。

Office自身及Windows的系统缓存不属于本软件私有存储；本轮只改变本程序及其随包组件的写入路径，不改系统或Office设置。
