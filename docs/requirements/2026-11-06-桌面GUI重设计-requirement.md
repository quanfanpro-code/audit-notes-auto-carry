# 桌面 GUI 重设计需求

日期：2026年11月6日。状态：整理版，三份文档联合审阅，尚未授权编码。

本文只说明要解决的问题、范围、业务边界和验收结果。页面布局、操作步骤、后端接口及实现方法见设计；实施顺序、测试和证据要求见计划。本轮只改这三份文档。

## 一、要解决什么问题

审计附注自动搬运系统已有四种 Word/Excel 组合、多工作表、识别复用、配对搬运、公式核对和中断后继续能力。目前界面简单，结果主要是原始记录，使用者难以快速判断：

- 正在处理哪份文件，做到哪一步，还需要自己做什么？
- 哪些内容实际更新了，哪些保留了，原因是什么？
- 某个问题在哪里，怎样打开文件检查？
- 上次任务怎样继续，错认记录影响了哪些报告？

本版要做成方便日常使用的 Windows 桌面工作台：操作顺手，进度明确，结果易读，问题容易找到；界面与后端实际行为一致，不影响内核继续维护。

使用者是编制、检查审计附注的人员，无需编程知识。主要场景是：选一对文件并开始，结束后先查问题、再打开新副本，随后换文件办理下一份报告。历史续跑、人工答复、公式核对和识别记录管理围绕这一过程提供帮助。

## 二、本版范围与业务边界

### 已确认的范围

- 一次办理一份任务；做好下一份操作和历史任务，不增加排队或同时搬运多份。
- 增加识别记录查看、停用、冲突处理和受影响历史任务查询；正常复用仍自动进行，无需逐表审批。
- 参考 audit-system 的设计理念和技术路线，改善整个操作过程与结果阅读。
- 本轮按需求优先工作流形成需求、设计、实施计划，停在编码前。

### 沿用的业务规则

- A 是需要填数的文件，B 是提供本次数据的文件，两端均可为 Word 或 Excel。每端一份文件，Excel 可选一张或多张工作表，一次是一套报表。
- 语义识别、配对、期间、单位、名单、清尾、续表、标题保护及跨端跨格式复用均按现行内核执行，不增加另一套判断。
- 复用已有识别解释；金额、名单、位置和标题仍取本次文件，不能搬用旧任务数据。
- A 端 Excel 纯数字算式按普通金额处理；引用公式保留，由本机 Excel 重算后与 B 核对。金额相等只说明“本次金额一致”，不证明公式逻辑正确。
- 原件保留，结果另存新副本；现有文件变更检查、中断续跑及人工回写 Word 能力保留。
- 识别记录默认仍放项目下“识别记录”，不另建记录库，不改变用户已决定的目录政策。

### 本稿提出的界面边界

结果页负责查看、筛选、定位和复制，实际编辑在 Office 中完成；人工回写另有入口。本版不做内嵌 Word/Excel 编辑器、手工配对、直接修改模型解释、自动修复公式或自动重跑受影响报告。

也不增加公司年度登记、账号、多人协同、云同步、删除历史、清空记录，以及与 GUI 无关的内核优化。具体页面和技术取舍仍随设计、计划一起审阅，不把文档形成视为编码许可。

## 三、必须做到的功能

| 使用环节 | 用户需要得到的结果 |
|---|---|
| 打开软件 | 双击进入独立窗口；缺少运行条件时知道原因和处理办法，不要求手工启动服务。 |
| 新建任务 | 明白 A 收数、B 供数；通过 Windows 窗口选文件，Excel 可选多张可见工作表；常用设置可沿用，不必登记公司、年度或模板。 |
| 查看进度 | 看懂正在处理哪份任务和实际阶段；区分复用、新识别、重认和未精读，不编百分比或剩余时间。 |
| 中断与继续 | 运行或等待答复时都能中断；已停下与正在中断有区别。能继续指定旧任务，不能继续时知道原因，旧成果保留。 |
| 人工答复 | 找到本任务等待的材料，复制、粘贴答复后继续；输入有误时保留内容并说明原因，不要求手填目录或编辑记录文件。 |
| 核查结果 | 先看到结论和需处理问题，再按业务表查明细、原因及依据；能比较 A 原值、B 本次值和有证据的 A 最终值，打开对应副本或原文件。 |
| 查看历史 | 按时间、文件、状态找任务；重启后仍可查看，继续旧任务与另开新任务明确区分。 |
| 管理识别记录 | 查已识别含义、依据、来源与使用情况；停用或处理冲突前看清目标和影响，处理后列出实际受影响任务。 |
| 设置与人工回写 | 保存模型连接、金标准及复用设置；测试连接如实说明检查了什么。人工回写使用原桥接，把已保存修改写入关联 Word 的新副本。 |

“再做一份”保留常用设置、清空两端文件；有意沿用旧文件时使用单独的新建入口。复用开关显示后台实际生效状态。失败要保留已经填写的有效内容，不要求用户从头再来。

## 四、结果可信与前后端配合

1. **以实际处理为准。** 对应成立不等于已经写入；标题撤回、写回撤回、公式保留、回读差异和未处理内容都要如实显示。不能把部分保留写成全部完成。
2. **缺资料就说明缺口。** 未取得的最终值不能用 B 值代替；空白、0、读取失败和未记录分别表示。名单前导零及金额精度不能被展示改坏。
3. **操作作用于明确任务。** 查看历史不改变正在运行的任务；快速换文件、切任务或重复点击不能串结果、误中断或重复执行。服务断开不等于任务失败。
4. **当前文件和历史核验分开。** 文件移动、删除或人工修改后要提示；不能拿旧核验结果声称当前文件仍正确。旧任务缺资料仍保留可读部分，不强制迁移或重跑。
5. **展示只整理已有事实。** 必要时补记原流程实际发生的动作和回读结果；不再次调用模型，不重复配对、搬运或新增财务判断。展示资料出错与成品是否生成分开报告。
6. **保护原件和已有工作。** 安全结束写文件后才能退出；不强杀用户 Office。停用记录不改写历史报告；替换已有答复先确认并备份。
7. **设置真实且不泄露密钥。** 正在执行的任务不被新默认设置改变。密钥不回显或混入任务材料；外部模型会接收所配置的识别材料，不能宣称所有资料都不外发。

## 五、易用性要求

采用紧凑、清晰、一致的工作台；主要操作明显，复杂依据按需展开，不让大日志、巨大统计卡或装饰挤占结果。

结果按“任务结论 → 业务表 → 明细 → 依据”逐层查看。支持筛选、搜索和连续查看问题，返回后保留查看位置；问题数量写清是表、格还是问题条数，不混算成功率。

重要错误、待核与撤回持续可见，文字说明不能由颜色代替。中文、长名称和金额能完整查看及原样复制；键盘可达主要操作，焦点清楚。小窗口和常用显示密度下仍能操作，不要求用户修改系统显示设置。

具体布局、控件、字号、响应时间目标及测量方法放在设计和计划中。易用性必须通过实际操作验证，不能只看效果图。

## 六、验收标准

以下均为编码后的验收要求，本轮未执行。保留原 G01—G30 编号便于追踪；具体样本、步骤和证据由计划逐项对应。

| 编号 | 场景 | 通过条件 |
|---|---|---|
| G01 | 启动、退出、缺少条件 | 独立窗口可用；安全退出并释放服务；错误有中文说明。 |
| G02 | 四种文件组合 | 界面可发起；真实副本金额、名单、标题正确，原件不变。 |
| G03 | 多工作表、隐藏表、快速换文件 | 仅提交本次可见选择，旧响应不带回旧表；原范围保护不变。 |
| G04 | 再做一份、重复开始 | 设置保留、文件清空；同一操作只开一份任务，不覆盖旧成果。 |
| G05 | 运行、等待答复、中断、异常重开 | 状态准确，能安全中断及继续，不出现虚假运行或完成。 |
| G06 | 运行时查看历史 | 活动任务不变，显示及操作不串任务。 |
| G07 | 完成、撤回、待核、回读差异 | 摘要与实际副本一致；旧记录相互矛盾时明确提示，不改旧记录。 |
| G08 | 公式结果 200 对 210、相等、无法计算 | 分别显示差额 -10、仅本次金额一致、无法核对，不称公式正确。 |
| G09 | 配对成功但未写入 | 显示最终处理，配对数不冒充写入数；原值和本次值有区分。 |
| G10 | 主表或续表标题失败，另有独立组 | 整组保留和独立组更新均与实际文件一致。 |
| G11 | 连续三份复用、关闭复用、记录不可用 | 展示与实际调用及本次文件一致，不增加模型核验步骤。 |
| G12 | 历史重开、旧任务、文件移动或修改 | 仍可查已有资料，明确缺口及文件变化，不假报当前核验通过。 |
| G13 | 续跑时输入、工作表或规则改变 | 原保护仍有效，拒绝原因明确，旧成果不变。 |
| G14 | 停用有下游依赖的解释 | 准确列出直接、间接影响；历史标待复核，无关组不误标、不改报告。 |
| G15 | 冲突变化、重复提交 | 差异可读，不自动择优；拒绝过时决定，重试不重复处理或假成功。 |
| G16 | 保存设置、连接失败、换金标准 | 保留有效设置和输入，不偷换任务依据，不回传密钥。 |
| G17 | 人工回写成功或失败 | 真实桥接生成新副本或报具体错误，不混同自动识别。 |
| G18 | 小窗口、不同显示密度、键盘操作 | 主要按钮和金额可用、可读；长列表可查，不靠缩小文字解决。 |
| G19 | 找到并连续核查问题 | 进入明细路径短，上一项/下一项与返回不丢筛选和位置。 |
| G20 | 多类问题同时存在 | 所有问题均可查；表数、格数、问题数有明确口径，不重复累计。 |
| G21 | 长数字、负数、0、空白、未记录、00123 | 显示及原样复制正确，类型和精度不变。 |
| G22 | 请求响应丢失、重复启动、旧响应迟到 | 一次操作只执行一次，后台不并行搬运，界面不串结果。 |
| G23 | 成品已生成但展示资料失败 | 成品仍可打开，缺口明确，不为显示重跑内核、不改旧索引。 |
| G24 | 名单、清尾、金额不变但标题换年、同名表 | 显示实际名单与标题动作，不因未参与金额配对漏报实际搬运。 |
| G25 | 旧版本不适用、真冲突、独立记录 | 存档状态与当前可复用性有区别，无关记录不被误标。 |
| G26 | 继续指定的非最近历史任务 | 使用原输入；无法可靠恢复时只读并说明，不能猜输入重跑。 |
| G27 | 打开副本、候选和材料目录 | 打开正确的登记文件，正式与候选区分；找不到时明确说明。 |
| G28 | 两端等待答复、答复错误、重复或替换 | 任务材料绑定准确，错误保留输入，替换确认备份后仍走原检查。 |
| G29 | 未保存内容、连接失败或服务断开 | 不丢输入、不假报完成或失败；恢复后查看真实状态。 |
| G30 | 首次使用者试操作 | 能完成选文件、找差额、打开副本、继续旧任务及查复用；记录卡点。 |

真实文件正确性、页面操作和易用性分别验证。固定模型答复可用于重复验收，不能用假 Word/Excel、模拟结果或漂亮截图替代最终文件核验；没有真人试用时如实列为未验证。
