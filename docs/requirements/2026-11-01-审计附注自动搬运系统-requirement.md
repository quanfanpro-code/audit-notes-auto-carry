## 一、背景与问题

同一批财务附注数据同时存在于两份文件：对外的 Word 附注（最终成品）和审计统计用的 Excel（记数）。两边说的是同一批业务事实，但行列编排、版式大相径庭，没法靠位置或名称直接对上，人工逐格查找、复制、回填费时且易错。

本项目新建干净的程序重写"审计附注数据自动搬运系统"：让模型先认出每个格子在说什么（语义识别），给每格发唯一的"语义身份证"；两边身份证逐字相同且各自唯一的格子才认定是同一件事，才允许把数据机械搬过去；最后生成 Excel 和 Word 两份更新后的新副本，每个搬过的数都能说清"凭什么搬"。原件一律不动。

需求的权威依据是《审计附注数据自动搬运-项目完整说明.html》（2026-11-01 版）及其十一条铁律。本文档只做归纳和本次决策记录，不替代该说明；两者不一致时，以用户本次已确认的决定优先（见第九节），其余沿用项目说明。

## 二、用户与使用场景

- 用户：Q老师，审计人员，无编程基础；单机 Windows 使用，中文界面。
- 场景 1（自动搬数主线）：放入 Word 附注原件、统计 Excel、金标准 → 系统走"提取→识别→比对→搬运→写回"五步 → 交付 Excel 新副本、Word 新副本、对应清单、未对应问题清单、回读验证记录。
- 场景 2（人工直接回写）：人工直接改更新后的 Excel（含未识别、未匹配的表格），保存后程序沿位置关联回写 Word 新副本。此场景不需要统计 Excel、模型、金标准。
- 交互方式：本地 WebUI，浏览器里操作；文件选择由本机程序弹出 Windows 选择窗口并记录真实路径，不要求手填路径；处理和回写都按真实路径读取你已保存的当前文件（浏览器文件框拿不到本机路径，且上传副本不会跟随 Excel 后续修改，故不用）。

## 三、功能范围

1. **提取**：把 Word 各表格提取成提取表 A（Excel），保留行列、合并关系、空白、表前后原文上下文，以及每格与 Word 的物理位置关联。提取产物含**带连接 Word 副本**（桥接的带连接报告，回写的必需输入），登记进接续记录。复用旧项目的 Word 桥接（编译产物＋接口，按需抄用）。
2. **识别**：模型对 A、B 每格（含空白业务格和名称格）直接交付：对应金标准的槽位＋本格身份证（槽位编号＋各维度实际值，未知照实写"未知"）。硬要求：简短指令不超过 2000 字；必要表格、上下文和相关标准完整提供，不得为过字数检查删减识别依据（材料仍只留必要部分，不夹带无关合集、不重复展示）；表格转文字保结构（合并表头、多级表头、空白占位如实保留）；调用克制，每个必要范围只问一次，不整表重跑、不加核查模型或复核流程；模型直接交付逐格结果，不许"同上"式答复。
3. **识别模型配置**：设置页手动配置 API 地址（URL）、API 密钥、模型名（及超时等必要参数），程序按配置调用；不绑定特定命令行工具或服务商。
4. **比对**：程序逐格比对身份证，只连接逐字相同且各自唯一的；不猜、不补、不改写身份；不以金额、位置、名称、行号为对应条件；未对应项保留原样并逐项记清原因。
5. **搬运与 Excel 写回**：对应成立的把 B 原值机械放进 A 形成 A′，保存 Excel 新副本。0 是实际值照搬；已正确对应且 B 确实为空白则把 A 更新为空白；没有对应、读取失败、公式无保存结果的，保留 A 原值并列问题，不得当成空白清空。
6. **Word 回写**：读取用户实际保存的 A′，沿位置关联写入 Word 新副本；支持表内必要的增删行列（维护标签、样式、合并、位置关联）；与某张表明确关联的期间标题（如表前“截至××年××月××日”）随该表更新为采用来源的期间，日期来自识别结果，程序不得自行猜测（沿用桥接已有的标题更新能力，仅改原文唯一匹配的普通文字标题）；写完逐格回读验证；进度写入准确接续索引（断点可续）。
7. **人工直接回写通道**：独立于识别链可用；人工已保存的修改按实际保存结果回写，不重新取数覆盖。
8. **WebUI 页面**（最小集）：任务执行与进度、结果与未对应问题清单、设置（模型配置）、人工回写入口。

## 四、明确不做的内容

- 不自动改写 Word 表格外的一般正文（一般正文只作识别上下文）。例外：与某张表明确关联的期间标题随该表更新为采用来源的期间（见功能范围第 6 条）。
- 不保证复杂合并表的任意增删行列；处理不了的记为实现缺口如实报告，不从需求里永久删去。
- 程序全程零语义判断：不做同义改写、不推导身份、不补字段、不按金额位置名称猜对应。
- 不导入旧项目的历史识别答复作为结果或验收依据；"复用"仅指本系统自己的断点续接。
- 不做多用户、账号体系或对外发布；WebUI 只监听本机（127.0.0.1）。
- 不修改原件、金标准、历史答复和历史文件；只生成副本。
- 不引入双轮识别、同义复核、自动纠正循环、额外核查模型（旧做法，已否定）。

## 五、关键业务规则（沿用项目说明，此处只列要点）

- 身份证 = 槽位＋各维度的值，是对应判断的唯一依据；金额不属于身份证比较内容。
- 换期按识别出的角色配对（期末对期末、期初对期初……），实际日期各自保留；程序不看年份猜换期。
- 主体、报表范围、单位等指定维度照实保存但排除比较；其未知或缺失不阻止对应；参加比较的必要信息缺失才不自动对应。
- 名单（公司名、资产类别等文字内容）随 B 更新，经识别进结果；不许程序按行号、位置或金额安排名单。
- 未匹配、空白、零、无来源都不是删除行列的指令。
- 人工维护类内容（政策方法、税率等）不自动搬运，改完走人工直接回写。
