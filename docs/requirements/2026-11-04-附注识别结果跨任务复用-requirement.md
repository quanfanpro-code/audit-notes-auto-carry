# 审计附注自动搬运系统｜跨任务复用识别结果需求

2026年11月4日 · 已通过需求确认，作为方案设计依据

## 一、要解决什么问题

审计人员连续编制几十份甚至上百份集团报告。每份任务各有一份 Word 附注（A 端）和一份 Excel 数据表（B 端）。不同 Word 可能缺少几个科目，后续表的顺序随之改变。不同 Excel 通常沿用统一底表，没有业务的科目也会保留表格，留空或填零。现在每份新任务都要识别两侧材料，许多表重复调用模型。

目标是从第二份任务起，让程序自动沿用以前已经认清的表。是否复用取决于本次文件里实际看得到的内容，不需要知道文件属于哪家公司，也不要求审计人员逐表登记、选择模板或审批。

## 二、哪些表可以进入共用记录

**按业务表组判断。** 一张独立表算一组；主表和它的所有续表合为一组。以下条件须同时满足：

- 本组已完成识别且没有跳过。主表、续表、所属科目和覆盖范围明确，无漏行、漏列、未解释区域，名单序号在组内连续，无重号。
- 必须识别的格子都有有效金标准编号。金标准要求期间的格子有明确期间角色。不需要编号的表头、注释或例外位置，必须有明确用途及范围。
- 没有未执行的例外、缺失的列标签、重复配对键或其他妨碍解释的问题。配对暴露出的识别错误也会阻止入库；另一侧缺少对应业务表，本身不能证明本组识别有误。
- 已完成本组适用的检查，原文证据、解释、来源及版本均已完整保存并可读。未写完、损坏、已停用或版本不兼容的记录都不可用。“完成”标记本身不构成入库依据。
- 任务部分失败时，已独立通过以上条件的组仍可入库。全侧存在无法定位的漏段、影响边界不明或本组尚未完成必要检查时，该组暂不入库。

**分清来源与解释。** 第一次独立认好一张表，留下识别来源。以后直接沿用，只增加使用记录。固定证据和解释均相同的多份独立记录归为同一种解释，保留全部来源。同一固定证据却得到不同的科目、表名、槽位、期间角色、表组或行列解释，作为冲突，相关解释一律不自动选用。不按新旧、次数或多数表决。未经澄清的冲突，不因本次模型恰好给出其中一种解释而自行解除。

## 三、用什么证据认出同一种表

**程序只核对首次识别已经指明用途的原文、结构和位置。** 能机械对上才沿用；需要理解两句话是否同义、判断新增项目属于哪张表、猜测一个名称充当什么角色，就交回现有识别流程。不要求逐表人工审批，也不新增常规的第二次模型复核。

| 本次文件有什么变化 | 如何处理 |
|---|---|
| 金额、已标明的名单项名称不同 | 金额不参与复用匹配和身份判定。名单项名称可以变化，名单所占位置、数量、标签位置及行列用途仍须核对。读值、配对和回读全部以本次文件为准。 |
| 正常换年、日期不同 | 仅已标明用途的日期位置可变。本期期初、本期期末、上期发生等角色及其作用范围须能按已有证据逐一核对。角色变化、无法核实或日期有其他业务含义时，回退本组。 |
| 公司名称、章节编号或表标题序号改变 | 仅当首次已将具体位置标为报告主体名称或排版编号，才允许该处替换。保留其余标题文字和层级。构成业务分类的主体名称、章节含义或未标明用途的文字，不能一律剔除。 |
| 页码、物理坐标、表在文件中排第几发生变化 | 不作为身份。本次文件重新定位，表内相对关系、上下文和续表归属仍要成立。 |
| 固定行名、表头层级与顺序、合并关系、单位、币种或倍率改变 | 属于解释依据。该组回退。不得仅凭标题相似或列数相同继续用。 |

原文用于留证，变化位置的标注由首次识别给出。旧任务没有此类标注时，不自动推测。A 端旧记录中的“标题原文／新文”是一次任务的写回指令，**不得复用**。需要更新标题时必须从本次原文和本次目标日期生成本次指令，仍遵守原有可写条件；只有以前已明确标注的日期位置及替换规则可机械套用。无法生成或验证本次指令时，该组不能算完全命中，按原流程处理。

## 四、三遍识别怎样复用

| 现有步骤 | 采用旧结果的条件 | 条件不成立时 |
|---|---|---|
| 第一遍，分科目 | 旧科目划分能重新定位到本侧当前材料，所有需解释的位置都有归属，没有空档和冲突。 | 在本侧调用现有第一遍。 |
| 第二遍，分表 | 在本次科目划分下，所有业务表、续表、非表格段落均有依据，覆盖本侧当前范围。 | 在本侧调用现有第二遍，以本次边界重新核对各表组。 |
| 第三遍，逐表精读 | 一整组证据只有一种有效解释，全部行列、期间和续表关系均适用。 | 重认受影响的业务表组，不逐格、逐行拼接新旧解释。 |

每遍分别判断。第一、二遍若回退，已明确定位、证据仍相符的组可省去第三遍。混用新旧结果后，**对本次整侧重新检查**范围覆盖、表组归属和完整性，并按业务表组和现有配对规则检查序号连续性、重复键、必填槽位及期间。旧记录的“完整性通过”不能传给本次任务；本次 B 端完整性没有证实，不执行依赖它的清尾。

**A 端 Word。** 本次提取实际存在的物理表和表前原文，先查证据，不要求模型先认出表名。比如第二份 Word 少了中间的“存货”，后面的“固定资产”可按本次位置复用。被分页拆开的几张物理表必须作为一个业务表组核对。两张同名表分不清，或续表归属不同，就退回本组识别。A、B 的旧记录分别查，本次配对只使用本次 Word 和 Excel。

## 五、B 端 Excel 的可见范围与精读范围

**首次识别范围也随本需求调整。** 首次读取、复用检查、本次识别合集和完整性检查，必须使用同一套可见范围规则。

1. 有打印区域，取所选工作表各打印区域的**单元格并集**，再排除隐藏行、隐藏列。两块打印区域之间的空档不纳入，重叠格只算一次。隐藏工作表不贡献可见内容。
2. 没有打印区域，读取所选工作表可见且有内容的部分。有值（含零）或有公式就有内容；公式返回空字符串仍保留公式位置，缺少缓存值沿用现有读值异常规则。只有空格或格式的格子不独立扩大范围。已纳入表格内部的空白位置仍保留；与内容相关的合并关系作为结构证据，纯空白合并不单独引入新区域。不能把隐藏或打印区域外的合并起点文字补进可见材料；因此无法解释的表按原流程处理。
3. 可见范围决定“读得到什么”。本次 A 端需要的科目决定“B 端哪些表需要精读”。可见但本次跳过的表，应记录跳过原因，不得算成已精读。上次 A 无“存货”、这次 A 有“存货”，就补认上次被跳过的 B 表。
4. 优先对整张底表核对布局。布局完整命中，可沿用分科目、分表和所需表组的精读解释。存货表留空或填零不触发重认。打印区域外或隐藏的辅助公式即使发生改动，只要可见结构未变，也不触发重认；搬运仍读取可见格的本次值。
5. 缩小打印区域或重新隐藏行列后，把不可见内容从本次合集、配对和完整性范围剔除。扩大范围、取消隐藏或插删行后，重新定位并核对受影响的**整个业务表组**。若无法确认变化边界，回退相应整侧划分；不得沿用已经移位的旧坐标。

## 六、错认、版本和客户资料

- **版本失效。** 以金标准的实际内容版本和识别规则版本共同控制复用。任一变化、缺失或不可核验，旧版记录均不自动使用；新任务按当前版本重新形成有效记录，记录具体原因。规则版本涵盖影响认表、范围、证据或解释的规则变化。不能仅按文件名或更新时间认版本。
- **影响追溯。** 发现解释错误后，自动停用该解释版本，沿来源与使用关系列出直接、间接受影响的任务和表，标记“受影响、待复核”。历史文件和产物不自动重跑或覆盖。是否重跑由用户另行发起；原文件已移动、删除或改变时，仍保留影响记录，不换用其他输入。
- **资料保护。** 共用记录及其中的客户名称、原文、来源只存放在本机非同步位置，不提交 Git，不随网盘同步。旧任务名称、原文和路径不进入本次报告及对外交付物；内部追溯与交付文件分开。
- **运行记录。** 按任务、侧和业务表组记录复用、重认或跳过及原因；另按侧统计三遍各自的实际模型调用次数，区分普通识别和重试。记录只说明证据是否匹配，不能据此认定首次业务解释正确。

## 七、验收场景

使用固定模型答复或已审定基准，在同一输入和当前可见范围下比较“完整识别”和“启用复用”。核对科目、业务表组、槽位及期间、本次坐标、标题、配对、清尾和回读。以下是未来验收条件，本次只静态核对需求。

| 场景 | 通过条件 |
|---|---|
| 首次任务、连续三份相同布局 | 首次正常识别；第二、三份均复用。同一解释多来源保留，第三份不因记录变多而回退。 |
| 同一结构对应两种解释 | 不选最新或最多使用的一条；该组回退，记录冲突原因。 |
| 一份任务部分失败；另含被跳过、缺槽位、漏行、期间未知、未执行例外、写入中断或配对暴露错误的组 | 独立通过全部条件的组可入库。上述问题组或不完整记录不能被下一份任务使用。 |
| A 删除中间科目，后面的表移位；另测同名表、期间列对调、续表归属不明 | 能唯一核对的完整组在本次位置复用。歧义组整组重认，不影响另一侧。 |
| 正常换年，A 标题需更新 | 读取本次标题原文，用本次目标日期生成新标题；从未取用上一份任务的标题写回指令。 |
| 一侧完全命中、部分命中 | 完全命中侧三遍调用均为 0。在无重试样本中，仅一个单物理表的业务组需精读时，三遍次数为 0、0、1；若需重分科目、重分表且一个单表组需精读，则为 1、1、1。两种情况下其余已命中组不调用模型。 |
| B 有两块不相邻打印区域，中间有改动；另测无打印区域 | 前者忽略中间格和隐藏格。后者纳入可见公式（包括返回空白），不因纯空格、格式或孤立空白合并扩大范围。 |
| 缩小打印区域、重新隐藏；另测扩大区域、取消隐藏和插行 | 不可见格从本次合集、配对及覆盖检查中剔除。新出现的内容要有归属；下方移位的表不沿用旧坐标。 |
| 区域外或隐藏的辅助公式变化，可见格的缓存值也变了 | 可见结构不变就不重复识别，读值和搬运使用本次缓存值。零、真实空白和缓存缺失仍分别处理。 |
| 上次因 A 缺科目，B 对应表未精读 | 本次 A 有该科目时补认 B 对应表，不把历史跳过算作命中。 |
| 一部分组复用，另一部分新识别；另测漏段、重号、重复键 | 对本次整侧重算覆盖和完整性，按组核验序号与重复键。未满足清尾条件时不清尾。 |
| 金标准或识别规则版本改变；另测错认已被多份任务沿用 | 版本不兼容时回退并记明原因。确认为错的解释停用，直接和间接受影响的报告及表列全；保留历史产物，文件缺失不触发自动重跑。 |
| 公司名或章节编号变化；另测固定行名、币种、单位或用途不明的名称变化 | 仅首次明确标注的可变位置允许变化；固定身份改变或需要推断用途的组回退并留原因。 |
| 客户资料与运行记录 | 本次对外交付物不夹带旧任务信息；本机共用记录不进版本库或同步目录；可按侧、按遍查调用次数，按表查回退原因。 |
