# 跨任务复用复核缺陷修复 · 设计

- 日期：2026-11-04
- 需求：`docs/requirements/2026-11-04-跨任务复用复核修复-requirement.md`
- 基线：`d1bc77b`

## 一、总体思路

复核报告暴露的不是零散 bug，而是同一个根因的多种表现：**证据只记录了"位置"，没记录"这个位置凭什么算同一个语义"**。期间角色、单位、列坐标、续表、标题都有这个毛病。

因此修复分两类：

1. **补证据**：把"可核对的语义特征"写进证据（列相对偏移、日期组、单位来源与原文、整组行、标题骨架与片段位置）。
2. **补门槛**：核对时逐条机械比对，任一条不成立就整组不搬；不能让"某一条通过了"代替"全部通过"。

统一原则：**程序不判断业务语义，只做机械核对；确认不了就回退，绝不猜。**

## 二、期间角色

### 2.1 证据里存什么（新格式）

每个日期格一项：

| 字段 | 含义 |
|---|---|
| `相对` | 相对整组左上角的坐标 |
| `值` | 首次识别时的日期（`YYYY-MM-DD`） |
| `月日` | 由 `值` 得出的 `MM-DD`，便于比对 |
| `表头原文` | 该列上方表头格的原文（如“期初余额”“2025-12-31”） |
| `角色词` | 从 `表头原文` 抽出的角色词（期初／期末／本期／上期；抽不出为空） |
| `期间角色` | 首次识别确认的语义角色（如“本期期初”） |
| `组序` | 本组内第几个日期，用于逐列比对 |

另存 `日期组.个数`。

`角色词`、`日期位置`、`期间角色` 都必须由**首次识别明确标注**，程序不从表头文本自行推断。复用时核对的是“当初这个角色绑在哪一列、哪个位置”，本次该位置的原文必须与记录**逐字一致**；只检查“本次标题里也含有‘期初’字样”不算核对。

### 2.2 允许复用的条件

按顺序全部满足：

1. 每个日期位置**仍是日期**。
2. 有角色词的列：本次**同一相对坐标**的表头原文必须与记录逐字一致，且该列仍绑定同一个 `期间角色`。表头挪了位置、或原文换成另一个角色词，都算不符。
3. **每列的月、日与记录一致**。
4. **全组所有日期的年份差相同**（`Δ = 本次年 − 记录年`，全组 Δ 相等）。
5. 日期个数与记录一致。

第 3、4 条必须同时满足：`2024-12-31、2025-12-31 → 2025-06-30、2026-06-30` 虽然 Δ 都是 1，但月日变了，重认；`→ 2026-12-31、2025-12-31` 月日没变但 Δ 为 2 和 0，也重认。

### 2.3 必须重认的情况

- 月日变化、年差不一致、日期不再是日期、个数变化。
- 角色词对调（如“期初余额”与“期末余额”互换）。
- **单日期且无角色词、且没有独立期间依据**（上下文未写本期起止）。

角色比较**分组进行，不合并**：

- 期初组（期初、上期）：组内各列日期互相比较，出现矛盾即重认。
- 期末组（期末、本期）：同样只在本组内比较。
- 跨组：期初组的日期不得晚于期末组的日期，否则判矛盾、重认。
- “本期”只与“本期”比、“上期”只与“上期”比，不得把“本期”当“期末”、把“上期”当“期初”。

这些比较只用于**发现矛盾**；顺序正常不能反过来证明角色正确。

### 2.4 重认与整组保护

- **无法复用先重认**；重认成功就按正常流程搬运，不受影响。
- 只有“重认后仍不能确认”或“本次 A、B 口径确实不一致”时，才对这一组做整组保护。
- 整组保护的完整范围（缺一不可）：
  - 该组全部金额格保留原值；
  - **名单名称、合计、小计行保留原值**；
  - **清尾不做**；
  - 标题不更新。
- 不允许出现“金额没动、客户名称换了”，也不允许“明细保留、合计更新”。
- 其他组照常搬；问题清单写明组（科目/表名）、原因、涉及范围。

## 三、金额单位

### 3.1 证据里存什么

沿用 `作用范围`（币种、单位），新增：

| 字段 | 含义 |
|---|---|
| `单位来源` | `表前` 或 `表内` |
| `单位原文` | 首次识别据以确认单位的原文片段 |
| `表内单位位置` | 若依据在表内，记相对坐标；表前依据为空 |
| `适用范围` | 首次识别确认该说明管到哪（整表／单列） |

`单位来源`、`单位原文`、`适用范围` 同样由**首次识别标注**，程序不自行从句子里猜哪个单位管哪一列。同一张表有多个单位时按列各存一份，不得只存表级一份。

### 3.2 允许复用的条件

满足任一即可：

1. 本次上下文能解析出单位，且与记录**一致**（币种、单位、倍率都一致）。
2. 本次上下文没有单位说明，但记录里的 `表内单位位置` 在本次仍可读、文字与 `单位原文` 一致。

并且：本次上下文的单位说明不能与表内单位**冲突**。

### 3.3 必须重认的情况

- 单位或币种不同（元 / 万元、人民币 / 美元）。
- 表前与表内互相矛盾，且旧证据无法说明各自适用范围。
- 旧证据靠章节说明，本次该说明消失，表内也没有独立依据。

### 3.4 重认与整组保护

- 遵循 2.4：**先重认，重认成功即正常搬运**；只有重认仍不明确，或本次 A、B 两侧单位确实不同，才整组保护。
- 口径不一致时不做任何换算，整组保留原值（含名单、合计、小计、清尾与标题），绝不写一个按旧口径算出的数。
- 同一张表按列使用不同单位时，**按列分别留证、分别核对**：每列记自己的单位来源、原文、适用范围；一列不符只影响该列所在组的判定，不得用表级单位覆盖全表。

## 四、列坐标与续表

### 4.1 列坐标

| 方案 | 做法 | 结论 |
|---|---|---|
| A | 存**相对业务表左边界的 1-based 偏移**，还原时 `get_column_letter(左 + 偏移 − 1)` | 推荐 |
| B | 存工作表绝对列号，还原时直接用 | 业务表整体右移后就错，不可用 |

现状把绝对列号存进“相对列”，还原时又加左边界，等于加了两遍。改为：

- 抽取：`偏移 = column_index_from_string(字母) − 左 + 1`，不再用 `ord()`（`ord('AA')` 只认首字符，跨 Z 必错）。
- 槽位、`期间角色按列` 的键同样改成偏移。

### 4.2 续表

| 方案 | 做法 | 结论 |
|---|---|---|
| A | 整组抽行：遍历组内每张表，行相对整组顶；列**在核实一致时**沿用主表 | 推荐 |
| B | 每张表各自抽一份解释 | 体积翻倍，但结构不同时更安全 |
| C | A 为主，核实不通过时退化为 B | 选定 |

**续表沿用主表列解释的前提（全部核实）**：列顺序一致、期间一致、标签位置一致、单位与适用范围一致。任一条不满足，就保留续表自己的解释（记录里有的话）；记录里没有，整组重认。不允许“列取主表”硬套。

同时修 `应用精读`：按各表行范围切分整组行，续表不再拿到空行；续表有独立槽位、例外时一并保留。

验收加一张**续表列顺序不同且有独立例外**的样本，检查最终 Word 的具体格子，不只看结构清单。

## 五、标题

| 方案 | 做法 | 结论 |
|---|---|---|
| A | 按片段在原文中的位置**一次性组装**（切片拼接） | 推荐 |
| B | 顺序 `replace`（现状） | 第二次会命中刚写入的值，已验证出错 |
| C | 从后往前替换 | 可行但依赖“后一片段在前一替换点之后”的隐含前提，不如 A 直白 |

复用标题的日期提取同样改为按位置取，避免第一个日期被重复分给第二个角色。

第二遍命中、第三遍重认时：标题规则随**组结构记录**保存，第三遍重认后从第二遍记录恢复；恢复不了就整组保护（标题与数值都不动）并留问题。

## 六、普通底表的复用

| 问题 | 做法 |
|---|---|
| 表头“期末余额”被当金额格 | 数值格只取**数据行**（排除表头行、标签行）；表头文字仍由固定文字核对 |
| 合计金额变化触发重认 | **第一遍与第二遍都要改**：`建证据_分科目` 的段末行原文、`建证据_分表` 的首行/末行原文，一律只取文字格、剔除金额格；两处核对同步 |

第一遍现有代码把段末最后一个金额当作定位依据，只改第二遍仍会在第一遍整侧回退。

验收：只改合计金额、保留普通文字表头；断言第一遍不重认、第三遍不重认，且最终搬的是**本次金额**。

## 七、入库门槛

| 方案 | 做法 | 结论 |
|---|---|---|
| A | 发布推迟到组内铺格、例外、编号核对完成之后；`可发布` 同时补漏行/漏列/缺编号/歧义/未执行例外的判定 | 推荐 |
| B | 只补 `可发布` 判定，时点不动 | 时点在前，坏组仍会先成为候选 |

A 的两处都要做：时点后移是根因，门槛补判定是兜底。

## 八、无打印区域时的可见范围

表区依据按优先级取，取不到就回退：

1. 已设置的打印区域（多区域取并集）；
2. 已确认的业务表区域（上下文的 `first_row`/`first_column`/`row_count`/`column_count` 或命名区域）；
3. 两者都没有：**回退，不复用**，不靠非空格的位置猜边界。

在已确认表区内：

- 内部空白格保留（如 B1）；
- 可见合并的从属格保留（如 A2）；
- 表区外仅因隐藏列远处辅助内容产生的空白不纳入（如 A88）。

| 方案 | 做法 | 结论 |
|---|---|---|
| A | 先定表区，再按可见格聚段；表区内空白与合并从属格随所在段保留 | 推荐 |
| B | 直接对可见内容格聚段 | 找不回空白格，B1、A2 会漏 |
| C | 可见内容的最小外接矩形 | 会把角落空白纳入，正是当前 bug 的另一种形态 |

用原反例定验收：表区 `A1:C3`、合并 `A1:A2`、隐藏列第 88 行有辅助文字。要求 `B1` 与 `A2` 保留、`A88` 不纳入。

## 九、停用追溯与登记

1. **依赖登记补全**：初次发布时，本组实际复用过的版本（含本轮刚独立发布的上游）全部写入 `依赖`，不再只记跨任务那一部分。
2. **停用传播**：停用 `v1` 时沿 `依赖` 反向遍历，把直接与间接下游**同一批次**标为 `已失效`，并记录 `失效因上游`。无依赖链的同报告其他表不受影响。
3. **锁内重核**：`登记使用` 与 `停用` 在同一把跨进程锁内，拿锁后重读当前代次与状态。
   - 先登记后停用：该次使用进入受影响清单。
   - 先停用后登记：登记被拒，调用方改走完整识别。
4. **历史与恢复**：历史产物只标“待复核”，不删；纠正后产生新版本，旧下游不自动恢复。

## 十、规则版本

`规则摘要()` 改为对**实际拼入材料的全部规则正文**取摘要：分科目规范、分表规范、精读规范、指令常量全文。任一字节变化即产生新规则版本，跨任务复用与未完成任务续跑都失效。

不采用“人工维护的显式版本号”：漏改一次就失效，和现状同样危险。

## 十一、记录目录限制

抽出 `目录是否安全(路径)`：默认目录与显式目录共用同一判断（同步盘、项目目录、无法确认的位置都不安全）。不安全时**禁用识别记录簿**，完整识别照常继续，不阻断任务，并在运行记录里注明“复用已禁用及原因”。

## 十二、裁决幂等

请求先规范化（版本列表排序去重、补默认停用集合、统一字段顺序）再算幂等键；返回状态由**实际剩余有效版本**算出：仍有有效版本则是“已裁决”，否则“全部停用”。

## 十三、数据流（修复后）

```
首次任务（无可用记录）
  → 三遍识别，产出解释
  → 建证据：列偏移、日期组（值/月日/表头原文/角色词）、单位来源与原文、整组行、标题骨架
  → 组内铺格、例外、编号核对全部完成
  → 才允许发布；发布时写全依赖（本轮复用的版本）

后续任务
  → 取快照（版本/规则/证据版本逐项校验）
  → 形状与固定文字核对（含表头原文、合计行文字骨架）
  → 期间：月日一致 + 全组年差一致 + 角色词绑定
  → 单位：上下文或表内证据一致，且无冲突
  → 任一条不成立 → 整组不搬、重认
  → 重认仍不能确认 → 保留原值、列问题
  → 命中 → 锁内登记使用（重读状态）→ 按本次文件重读日期与数值 → 搬运 → 回读
```

## 十四、错误处理

| 情况 | 行为 |
|---|---|
| 证据版本不符 | 该记录不可用，不计为冲突 |
| 日期解析失败 | 该组不可用，原因写清位置与文本 |
| 单位解析失败或冲突 | 该组不可用，原因写明两处来源 |
| 记录簿目录不安全 | 禁用复用，完整识别继续，运行记录留痕 |
| 同一形状多份解释 | 不选，整组回退；记录簿已停用的按停用处理 |

## 十五、测试策略

1. 全部走**正常任务入口**（`运行任务`）。
2. 每条复用用例同时断言两件事：**最终金额格证明搬对了**，**调用次数证明该复用的时候确实复用了**（该重认的组必须重认）。只断言其中一件不算通过。
2. 期间与单位各按需求第六节的用例逐条覆盖，包含“正常换年可复用”“对调必须拦”“元改万元查到最终金额格”。
3. 停用：两进程交错，两种先后顺序都跑。
4. 裁决：走内部管理入口，断言批次不新增、返回状态与剩余有效版本一致。
5. 变异检查复跑：把新校验逐条改坏，确认测试变红。
6. 回归：全量 + 真实 Word 三组。

## 十六、迁移与回滚

- **迁移**：证据版本号递增，旧记录一律按“版本不符”退出自动复用；记录文件与使用历史保留，仍可追溯哪些报告用过哪些版本。首次遇到一张表按新规则重认。
- **回滚不等于关闭复用**。退回 `d1bc77b` 后，旧程序默认开启复用（`已启用` 的默认值），仍可能读取保留的旧格式记录；即使显式关闭复用，旧版的双日期标题缺陷依然存在。
- 回滚安排：
  1. **显式关闭复用**（环境变量或配置），不依赖默认值；
  2. **新建任务**，不复用旧任务目录；
  3. 新旧记录簿目录**隔离**，旧记录保留但不被读取，追溯仍可查；
  4. 涉及已知标题缺陷（同一标题含多个日期）的任务**不得据此恢复生产**，须按新版本重跑。
- **不设复用率下限**：切换后复用率必然下降，没有可比集团样本，报告中写“实际复用率变化尚未验证”。

## 十七、方案比较汇总

| 缺陷 | 备选 | 选定 | 理由 |
|---|---|---|---|
| 期间 | 只比月日／只比年差／月日＋年差＋角色词 | 月日＋年差＋角色词 | 单一判据都有反例；组合后可机械验收 |
| 单位 | 严格读不到即拒／宽松沿用／按证据来源分级 | 按证据来源分级 | 既不误用旧口径，也不因表前没写就一律重认 |
| 列坐标 | 绝对列号／相对偏移 | 相对偏移 | 绝对列号在表整体右移后必错 |
| 续表 | 整组抽行／每表各抽 | 整组抽行 | 行数不丢且体积不翻倍 |
| 标题 | 位置组装／顺序替换／倒序替换 | 位置组装 | 唯一不依赖隐含前提的写法 |
| 入库时点 | 后移＋补判定／只补判定 | 后移＋补判定 | 时点是根因 |
| 可见范围 | 可见格聚段／最小外接矩形 | 可见格聚段 | 矩形会纳入角落空白 |
| 停用传播 | 递归标失效／查找时逐级查 | 递归标失效 | 影响清单要能直接列出 |
| 规则版本 | 自动摘要全文／人工版本号 | 自动摘要全文 | 人工版本号必漏 |
