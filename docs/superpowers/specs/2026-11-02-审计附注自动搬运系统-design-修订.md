# 设计修订：配对口径与搬运范围

日期：2026-11-02
依据：`2026-11-02-审计附注自动搬运系统-需求补遗.md`、第五阶段复核报告 18 条。
范围：只改识别、比对、搬运、结构维护、流程、服务层与说明文档。不动提取与 Word 桥接链路，不新增依赖。

## 一、这次改什么

| 问题 | 现在的做法 | 改成的做法 |
|---|---|---|
| 一个编号盖多行时无法区分 | 只认编号，多行就判“重复” | 按编号对应；名单项再加序号。是不是名单、排第几由识别给，不按槽位名或出现次数推断 |
| 同一项的期初、期末共用一个编号 | 不区分，容易两格互撞或串期 | 每格再带 `期间角色`，配对键＝编号＋序号＋期间角色；**期间只在金标准要求时进配对条件**，年份不参与，换年照常更新 |
| A、B 的表号不可能相等 | 各用本侧表号直接比，整组对不上 | 先用 `科目＋表名` 把两侧表对上，再比里面的格；同侧同名多张交人工 |
| 名称列被整列丢掉 | 只处理金额列 | 项标签即名称：名单项的标签（行标或列标题）随项从 B 搬；固定项和汇总项的标签不搬 |
| 名称被当成“配不配”的条件 | 逐字比名字 | 名字是内容，从 B 取，不参与判断 |
| 合法 P 类编号被判缺失 | 只认 C 开头 | 按金标准里真实存在的编号判断 |
| B 比 A 少时没处理 | 不产生操作或误判重复 | 只对名单做尾部清空；固定项保留原值 |
| B 比 A 多时装不下 | 照配，配出脏数据 | 整表停下，交人工加行或加列 |
| 模型给的表外坐标照收 | 不校验 | 坐标、行号必须落在本表内，否则判失败 |
| 表头日期不随期间更新 | 靠槽位名含“标题”触发 | 按该表真实段落构造，不靠名字碰运气 |
| 回读有差异仍算完成 | 无条件写 done | 差异非空即失败 |
| 整表口径不同仍硬搬 | 不比较 | 币种或金额单位冲突、期间角色或跨度不相容才停；同类期间换年照常更新 |

## 二、数据怎么流

八步不变，只把每步的产物和失败点写清楚。

| 步 | 输入 | 产物 | 什么情况停 |
|---|---|---|---|
| 1 提取 | Word 原件 | 表A、带连接Word、上下文 | 桥接报错、命名区域缺失 |
| 2 分科目 | 整份表格文字 | 每段的科目归属 | 科目不在清单、行范围重叠 |
| 3 分表 | 同上＋科目划分 | 每张表的行范围与表名 | 表名不在该科目清单、范围跨科目 |
| 4 逐表精读 | 单张表文字＋候选槽位 | 列清单、行清单、作用范围、例外 | 坐标越界、漏行、编号不在候选 |
| 5 配对 | A 合集、B 合集、两侧结构清单 | 对应清单 | 项数 B 多于 A、整表口径冲突 |
| 6 搬运 | 对应清单、B 合集 | 变更清单、问题清单 | 读不到值（记问题，不停） |
| 7 写回 | 更新表、带连接Word | Word 新副本 | 桥接拒绝 |
| 8 回读 | Word 新副本、变更清单 | 回读差异 | 差异非空即失败 |

## 三、关键规则怎么落

### 3.1 序号与期间角色：定位到一项里的哪一个格

**先定业务表组。** Word 分页会把一张业务表拆成两张物理表，所以计数前要先确认：哪几张物理表属于同一张业务表、哪张是续表。这个归属由**第二遍识别交付**，写进结构记录的 `表组`；定不下来就交人工，不凭表名相同硬合。组标识要能在本侧区分同名表。

**两侧靠“科目＋表名”认成同一张表。** A 的表在 Word 里叫 `TA_008`，B 的表在 Excel 里叫 `word附注!120`，两个号不可能相等。所以配对前先按 `科目＋表名` 把两侧的表对起来（续表已并进同一个组）；同侧出现两个完全同名的业务表时，无法确认谁对谁，该科目交人工，不按位置猜。

**序号由识别给。** 第三遍为每个明细项（一行或一列）标一个 `序号`：这是同一个编号在本表的第几项。

- 固定项只有一项，序号留空（一项里可能有两格，比如期初和期末，靠期间角色分）。
- 名单项按出现先后给 1、2、3。排在行上就按行序给，排在列上就按列序给——识别看得见整张表，按阅读顺序数即可。
- **序号只给一个方向。** 名单排在列上时，行只是期初／期末，行上不要再给一套号；两边都给号判失败，交人工。
- **识别失败的项也给序号**，只是它里面某些格的编号为空。后面的项不往前挤。
- 校验“同编号多行要不要补序号”也按方向走：列上已有号时不管行；行是项时，只有两行连期间都分不开（同一个编号、同一个期间角色）才要求给号。同一项期初、期末各写一行是正常结构，不是两个名单项。

**期间角色也由识别给。** 光有编号和序号还不够：同一个编号可能同时管住一项的好几格。真实金标准里：

- `C-N049-T001-S001`「应付职工薪酬分类余额」的列路径只写“余额”，来源记录里既有期初也有期末。
- `C-N087-T001-S001`「库存现金余额」的来源里同时有“期末余额”和“期初余额”。
- `C-N067-T001-S317`「现金等价物余额」同一编号盖住四格：本期期初、本期期末、上期期初、上期期末。
- `C-N095-T001-S103`「委托代销手续费」同一编号同时用于本期发生额和上期发生额。

所以每个格还要标一个 `期间角色`，统一七种写法：

| 写法 | 什么时候用 |
|---|---|
| 本期期初／本期期末 | 表里同时有本期和上期两套期初期末时 |
| 上期期初／上期期末 | 同上，指上期那一套 |
| 本期发生／上期发生 | 发生额类，区分本期和上期 |
| 未知 | 原文看不出，或识别没把握 |

**期间写两层时，两处各交一半。** 真实表里常见“列写本期金额／上期金额、行写期初余额／期末余额”，四格的期间各不相同。这种表不可能只靠一处写完整角色，所以格式允许交“两半”：

| 交法 | 例子 | 程序怎么用 |
|---|---|---|
| 完整角色（七种之一） | 列写「本期期末」 | 直接采用 |
| 只交期间的一半 | 列写「本期」「上期」 | 与另一处的「期初」「期末」拼成完整角色 |
| 只交时点的一半 | 行写「期初」「期末」 | 另一处没写期间时按「本期」记，即本期期初／本期期末 |

两处各写完整角色时必须一致；两处给了矛盾的一半（一边本期一边上期，或一边期初一边期末）判冲突、交人工。只有「本期」「上期」而拼不出时点，记「未知」，不猜。拼出来的仍是那七种写法，配对规则不变。

**实际年份不参与**：2024 年期末配 2025 年期末是正常换年，照常更新，参与比较的只有上面那个写法。行上能看到具体日期时（如 `2025-12-31`）一并交给程序，换期要用它，不许丢。

**“未知”不是证据。** 该编号声明 `period` 必填时（实测 11,395 条），任一侧是“未知”就不配、记问题、整项保留；两侧各只有一格也不例外——唯一那一格同样可能是期初或期末。没有 `period` 维度的编号（实测 1,422 条，多为名称类文字槽位）不受影响。程序读金标准判断，不靠“有没有第二个候选”猜。

合计行／列不占序号，也不计入清尾，但仍是要搬的业务格。

**为什么不让程序自己数。** 程序能看到的只有“这个编号出现几次”，次数是结果不是性质；也看不到哪个格是债券、哪个是固定资产类别。真实反例：

- `C-N049-T001-S001` 槽位名**没有**尖括号，行路径却是 `<薪酬类别或类别集合>`，两个不同薪酬类别合法共用一个编号。按名字判会误判成固定项，把正常数据当重复拒掉。
- `C-N014-T001-S001` 所在“债权投资／债权投资的情况”整表 6 条全是金额槽位、没有文字槽位，但行路径是 `<披露项目>`。按“整表有没有文字槽位”判，会把债券名当固定标签，搬出“甲债券的名字＋乙债券的金额”。

实测规模（只说明名字判据不可靠，不能反过来当判据）：行路径带尖括号 2,058 条、列路径 11 条、槽位名带尖括号 2,049 条；其中“沿项重复但槽位名不带”9 条（按名字判必漏）。尖括号是半角 `<` `>`。

**为什么不说横竖。** 一个维度是排在行上还是列上，是排版，不是语义。程序只认“第几个”和“这一格是期初还是期末”，不问方向。同一张表里名单既在行又在列的情况，金标准里一条都没有；真碰上就交人工。

### 3.2 项标签即名称

名称不是一个单独的格子，而是名单项的抬头：排在行上是行标，排在列上是列标题。搬运不再单设“名称格”，也不再要求名称槽位编号。

| 项的情况 | 判断依据 | 标签怎么处理 |
|---|---|---|
| 名单项 | 该行／列有 `序号` | 是内容，随项从 B 同一序号搬；行上写回行标，列上写回列标题 |
| 固定项 | 序号为空 | 是身份，不搬，原样保留 |
| 汇总项（小计／合计） | 角色为小计／合计 | 不搬 |

标签以外的文字列（另有编号的文字列，如“与本企业关系”）按普通数据格处理，靠编号＋序号＋期间角色配对、随项走。查不到编号 → 记“编号缺失”，整项不搬并列问题，**不许当固定标签糊过去**。

这样落下来有三个直接结果：

- 不需要给名称单独找编号，也就没有“名称编号给不出、整项被卡住”这条老问题；
- 甲债券换乙债券能整项换过来，列上的类别也一样——标签和数字同批取自 B 的同一项；
- 库存现金的金额不会被标签拖住，因为固定项的标签根本不参与搬运。

**列标题写在哪一行，由识别的「标签行」指定。** 表头常有两层：一层写类别名称，一层写“单位：元”。拿“数据行前最后一行表头”当名称，就会把“元”写进标题，留下旧类别名配新类别数字。所以列上成名单时，识别的「列」里必须给 `标签行`（这一列的名称在第几行）；没给、或指到数据行上，该表记「列标签缺失」，整表不搬，交人工。

**列标题的写入风险要单独验。** 行标是普通单元格，写进去安全；列标题常落在多级合并表头里（“账面原值”横跨四列，下面再分房屋、机器），往合并单元格写文字桥接能不能干，本期先写一条集成用例实测。写不进去时，含列标题写入的表退回人工，其他表不受影响。

### 3.3 配对

按 `科目＋表名` 把两侧的表对上，组内按下表判。**配对条件随编号变，不是一律三样**：先查这个编号在金标准里要不要期间，再决定期间角色进不进配对条件。

| 该编号 | 配对条件 | 期间角色 |
|---|---|---|
| 要求期间（有 `period`，必填） | 编号（＋序号，名单项）（＋分组，汇总格）（＋期间角色） | 进条件，七种写法按字面比较 |
| 不要求期间（没有 `period`） | 编号（＋序号，名单项）（＋分组，汇总格） | **不进条件**，原识别值照实保留 |

在两种编号上分别落到这几种情形：

| 情形 | 要求期间的编号 | 不要求期间的编号 |
|---|---|---|
| 序号为空，两侧各一格 | 编号相同、期间角色相同 → 对应 | 编号相同 → 对应 |
| 序号有值 | 编号、序号、期间角色三样都相同 → 对应 | 编号、序号相同 → 对应 |
| 合计、小计 | 按编号＋期间角色对应；多个同类小计再按分组归属 | 按编号＋分组 |
| 期间角色为“未知” | 未对应，原因“期间角色未知”，整项保留并列问题 | 不适用（期间不参与） |
| 同一组完整配对键下同侧多格 | 该表失败，交人工，不按顺序硬配 | 同左，且判重时同样不看期间 |
| 只有 A 有 | 未对应，原因“仅A侧有”；固定项保留原值，名单按清尾规则处理 | 同左 |
| 只有 B 有 | 未对应，原因“仅B侧有”；**不据此判“需要加项”**，项数另算 | 同左 |
| 编号为空或不在金标准编号集合里 | 未对应，原因“槽位编号缺失” | 同左 |

编号是否合法，用金标准真实编号集合判断，**不看开头字母**（P 类同样有效）。

期间角色七种写法：本期期初、本期期末、上期期初、上期期末、本期发生、上期发生、未知。表里只有一套期初／期末时一律记“本期”。**年份不参与**：A 写 2024 年期末、B 写 2025 年期末，角色相同照样配，实际日期取 B。

**“未知”不是证据。** 该编号声明 `period` 必填时，任一侧是“未知”就判 `期间角色未知`、整项保留，两侧各一格也不例外。

**不要求期间的编号，期间不同也照配。** 真实例子：`C-N019-T013-S006`（其他应付款／按交易对手方归集的期末余额前五名的其他应付款情况／`<单位全称>` ／款项的性质），`dimensions` 只有 `counterparty`，没有 `period`。A 写“本期期末”、B 写“未知”，或者两边写两个不同的已知期间，都必须判对应、把 B 的文字搬过来。原期间值在记录里保留，**不许为了让期间“不参与比较”去改写或删除原识别结果**。

未对应的每一格都要进清单，不许丢。

### 3.4 项数三种情况

**只对名单适用**；固定项不做清尾。**项数看两侧完整名单清单的项数（含识别失败的占位项），不看某个编号桶里有没有对方的记录。**

固定项和合计不占名单名额：B 多出一个固定项（比如今年多列了银行存款），配对时记“仅B侧有”，已对应的固定项照常更新，不停整表；B 少了合计，合计按“仅A侧有”保留原值，不能拿它去抵消 B 新增的名单项。只有 B 的**名单**项数多于 A 才整表停。

| 情况 | 处理 |
|---|---|
| 两边名单项数相同 | 序号相同的项整体覆盖（标签＋数据） |
| B 名单少于 A（含 B 明确写“本期无”） | 前面的项照常覆盖；A 尾部多出的项整项清空，问题清单逐项注明“B 无此项，已清空，请人工确认是否删行或删列” |
| B 名单多于 A | 整表停止，交人工加行或加列，不自动加 |

尾巴按**识别给的序号**认：列上成名单时列字母只表示位置，`AA` 不是排在 `Z` 前面，不能拿字母串比大小来数末尾。没给序号（固定项、汇总项）才退回物理顺序。

**A 里某格没认出编号，不是“A 少了一项”。** 项还在、序号还在，只是那一格配不上：该格记未对应，整项保留原样并列问题，同表其他项照常搬。绝不因为某个编号桶里查不到 A 的记录就判“B 有 A 无、需要加项”——否则一格的识别失败会把整张表停掉。

**序号必须按完整清单给，不能压缩。** 某项里某格识别失败（编号为空）时，该项照样占序号，后面的项不前移。否则 A 第 1 项会配到 B 第 2 项的金额，拼出 B 里根本不存在的“丙＋400”。

**清尾前必须先证明 B 完整**，四条同时成立：

1. 第一遍划分覆盖全部有内容行，无未解释空档；
2. 第二遍每段都归到表或标为非表格，无漏段；
3. 第三遍清单覆盖本组全部项，失败项也占位、也计数；
4. 名单本期 0 项时，识别结果显式写了“本期无”。

**第三遍四项校验通过，不等于 B 完整**——它只证明交上来的部分自洽。B 实际 3 项、前两遍只圈 2 项时，仍然不能清 A 第 3 项。四条不成立就不清尾，列出范围问题。

**固定项不清尾**：B 里没有某个固定项（今年没列库存现金），保留 A 的原值并列问题，不当成“B 无此项”。

### 3.5 整表口径

第三遍为每张表交作用范围，至少含币种、金额单位、期间角色与期间实际日期。配对前先看同一张表两侧的作用范围：

| 情况 | 处理 |
|---|---|
| 币种或金额单位不同（人民币元 对 人民币万元、对美元） | 整表停，交人工 |
| 期间角色或跨度不相容（期末余额 对 本期发生额） | 整表停，交人工 |
| 同类期间换年（期末 2024 对 期末 2025） | 正常处理，采用 B 的实际日期 |
| 一边有一边没有 | 以 B 为准，不拦，清单标注“口径未注明” |

换年是这套系统的主要用途，不能因为两句话字面不同就停。判断依据由识别结果给出（期间角色、跨度是否相容），程序不靠比对两段文字。

**这一步替代不了逐格的期间角色。** 两侧都同时含期初和期末时，整表口径是相容的，但表内两格仍要靠 3.1 的 `期间角色` 才分得开。

**日期标题与数据同进同退**：需要改表前日期标题时，标题与数字必须一起成功。标题无法唯一定位、无法安全替换时，该表数字不换、保留原样，列问题，其他表继续。不允许出现“2024 年的标题 + 2025 年的数”。

### 3.6 第三遍的六道校验

六道都过才算这张表做完；缺一道判失败，不标完成。

1. **坐标在本表内**：列字母和行号都落在这张表的范围内。
2. **行号在本表内**：行清单里的行号必须落在行范围内。
3. **行范围合法**：不重叠、不倒序、不跳出本表。
4. **逐项交付**：每个明细项都要有交代，要么给出内容，要么写明“此项不搬及原因”。整表只交表头不交明细，判失败。例外：名单本期确实 0 项时，写明“本期无”算已交付，不判漏交；没识别、读取失败、没找到对应业务表的，仍判失败。
5. **序号齐全**：名单项必须给序号，且在同一侧从 1 连续编到底；缺号、重号、跳号判失败。方向只有一个：列上有号就不再要求行给号；行是项时，同编号、同期间角色跨多行才要求补号。
6. **期间角色齐全**：每个数据格都要有 `期间角色`。可以交七种完整写法之一，也可以交「本期」「上期」「期初」「期末」这种两半写法，由程序按 3.1 拼成七种之一；拼不出时点记「未知」。别名、白话（“年末”“年初”）一律判失败。写“未知”允许，但该编号要求期间时，这些格配对时会被判 `期间角色未知`；该编号不要求期间时，这一项只作记录，不参与配对。

**整表判重在第 3 道之后、配对之前做。** 同一侧出现两组完整配对键相同（编号＋序号＋期间角色都一样，不要求期间的编号只看编号和序号），整张表判失败、一项都不许动，不按出现顺序硬配。重复项和正常项同时存在时更要整表停——上一版只停重复那一项，正常项照旧写进去了，这不合要求。

### 3.7 例外

第三遍交的“例外”要真正参与铺格：例外点名的位置按例外说明处理，优先级高于常规规则。**铺格子时必须真的读这张表**——现在代码只是把例外存下来，铺格时完全没用，这是要改的。程序处理不了的例外，列进问题清单，不按普通矩形硬铺。例外点名合并覆盖的位置，不产生独立格。

**「不搬」的业务格要留占位，不能一删了之。** 一格被标“不搬”往往正是因为它没法确认；把它从 A 的记录里删掉，搬运层就以为同项其余格都齐了，于是出现“乙债券／200／减值 10”这种新旧混搭。做法是：这一格仍进合集，标 `不搬`，配对时记“识别不搬，交人工”，搬运据此整项保留。只有「合并」覆盖的从属格才真的不铺。

### 3.8 回读

回读差异非空即判失败，步骤记为“回读不一致”，列出每一格的期望值与实际值。差异文件保留，不删证据。

### 3.9 结构信息怎么交给配对和搬运

现在配对只收 A、B 两个合集，结构信息拿不到。这次这样接：

- **合集记录里冗余带** `表组`、`序号`、`期间角色`、`期间必填`（该编号要不要期间，配对时决定期间进不进条件）、`角色`（数据格／项标签／汇总格）、`分组`，配对和搬运不必回头读文件就能分组。
- **结构清单提供**：`科目`、`表名`（两侧据此认成同一张业务表）、`完整性` 结论、`空名单`、汇总项的 `分组`。
- **配对入口改成** `建立对应(A合集, B合集, A结构, B结构)`。缺结构直接报错，不默认推断；先按 `科目＋表名` 把两侧表对上，再比较格。
- **搬运按 `表组＋序号` 分组**，项标签从 B 合集同组同序号取，取不到就整项不动。固定项按 `表组＋编号` 分组；该编号要求期间时再加期间角色，不要求期间时**不加**。

## 五、状态机

步骤取值：提取 → 识别A → 识别B → 配对 → 搬运 → 写回 → 回读 → 完成；另有三种终止态：待答复、回读不一致、失败。

“完成”只能在回读差异为空时写入。待答复保留已答部分，可续跑。

## 六、测试怎么补

每条修复先写一个能复现的失败用例，再改代码。至少覆盖：

1. 固定编号两侧顺序相反：库存现金、银行存款各自更新到正确项目，不判未对应，不清空 B 仍有的项目。
2. 名单按序号替换：同一编号两项、内容不同，序号 1 对 1、2 对 2，不串行。
3. 合计：明细全换后，合计取 B 的 900，程序不自行相加；两个分组的小计不串组。
4. 续表：A 分两张、B 合一张，各 4 项，正常处理；两张独立同名表不混配。
5. 项标签与数据同组：标签成功金额失败、金额成功标签失败，两种都断言整项保留原样并列问题。
6. 固定项标签不搬、金额照更新：库存现金 A 写 100、B 写 110，金额变 110，行标仍是 A 的“库存现金”。
7. 名单项标签随项搬（真实债权投资 C-N014-T001-S001…S006）：A 第一行“甲债券 100”、B 第一行“乙债券 200”，断言整行变“乙债券 200”，绝不出现“甲债券 200”。
8. 名单不由槽位名推断（真实薪酬 C-N049-T001-S001）：槽位名无尖括号、行路径带 `<薪酬类别或类别集合>`，给序号后两个类别正常配，不判重复。
9. 同一完整配对键下同侧多格才判失败：同一编号、同一序号、同一期间角色出现两格 → 该表失败；库存现金与银行存款两个不同编号各一格 → 正常对应；两个分组的小计（编号、期间相同但分组不同）→ 各配各的，不判重复。
10. 列上的名单能搬（真实固定资产 C-N038-T001-S001，列路径 `<资产类别>`）：A、B 各三列且类别顺序不同，断言按序号整体替换，列标题与数字一起换。
11. 列标题写入合并表头：往合并的列标题写新文字，断言桥接能写、回读一致；写不进去时该表退回人工并记录，不影响其他表。
12. 名单只有 1 项：B 明确写“本期无”且完整性成立，A 该项被清空并记录；B 未找到或识别失败，则不清空、列问题。
13. 固定项缺项不清尾：A 有库存现金、B 缺，保留 A 原值并列问题。
14. P 类编号：判“对应”而不是“缺失”；虚构的 C 开头编号要判缺失。
15. 别名：出现在实际送出的第三遍材料里。
16. B 少于 A（名单）：尾部整项清空，问题清单有记录。
17. 清尾前提：B 实际 3 项、前两遍只圈 2 项，拦住清尾并列问题。
18. 失败格占位：B 第 1 行金额缺编号、第 2 行完整；A 第 1 行保留，A 第 2 行按 B 第 2 行更新，不出现“丙＋400”。
19. B 多于 A：整表停，不产生变更；多一列同样停。
20. 正常换年：2024 对 2025，同为期末，按 B 更新。
21. 期间真冲突：期末对本期发生额，整表停。
22. 标题改不了：该表数字不换，问题清单有记录。
23. 标题正常更新：普通金额槽位、槽位名不含“标题”，本表日期仍按 B 期间更新；其他表标题不变。
24. 币种或单位不同：整表停。
25. 口径句不含“单位”“系指”（如“以下金额均以人民币万元列示”）：仍进材料，且被识别为口径差异。
26. 表外坐标、漏项、只交表头：判失败；明确写“本期无”的空名单不算漏交。
27. 序号缺号、重号、跳号：判失败。
28. 期间角色缺失或写法非法：某数据格没给期间角色、或写成“期初”这类裸写法，判失败。
29. 同一项期初期末分得开（真实薪酬 C-N049-T001-S001）：一项内期初 100、期末 120，B 为 200、220，断言两格各对各的，不判重复、不串期。
30. 期初期末排列相反也不串（真实库存现金 C-N087-T001-S001）：同一编号的期初、期末在两表的顺序相反，断言仍按期间角色配上，标签与整项数据一起更新。
31. 两套期初期末也分得开（真实现金等价物 C-N067-T001-S317）：同一编号盖住本期期初、本期期末、上期期初、上期期末四格，A、B 排列不同，断言四格各对各的，不撞号。
32. 两个“未知”不得配成一对：同一编号在一项里两格，A 本期期初标“未知”、本期期末标“本期期末”；B 本期期初标“本期期初”、本期期末标“未知”；断言 A 本期期初不被 B 本期期末覆盖，受影响格进问题清单，整项保留。
33. 唯一一格未知也不配（真实库存现金 C-N087-T001-S001）：两侧各一格、期间都标“未知”，断言不判对应、不写入，问题清单记“期间未确认”。
34. 不需要期间的编号不受影响：取没有 period 维度的文字槽位（如 C-N054-T003-S002），期间未知照常配对。
34b. 不需要期间的编号，期间不同也照配（真实款项性质 C-N019-T013-S006）：同编号同序号，A 写“本期期末”往来款、B 写“未知”保证金，断言判对应并搬入 B 的文字；两侧写两个不同的已知期间，同样照配；记录里的原期间值未被改写。
34c. 不需要期间的编号，重复判断不看期间：同侧两个 C-N019-T013-S006，期间角色不同、其余条件相同 → 判重复交人工，不能靠期间写法不同逃过重复检查。
35. 两侧表组标识不同也能对上：A 叫 TA_008、B 叫 word附注!120，按 `科目＋表名` 认成同一张表后正常搬运；同侧两张独立同名表交人工。
36. A 某格缺编号不误判加项：A、B 各两项，A 第 1 项某格缺编号 → 第 1 项保留并列问题，第 2 项照常更新，不报“需加项”。
37. 例外点名合并覆盖：不产生独立格。
38. 回读差异：步骤不是完成。
39. 加列：明确报不支持。
40. 实际插入空白行并保存：生成正确插行操作，插入后其余表位置不变。
41. 续跑：沿用原目录，不重跑已完成。
42. 人工改过的更新表：不被自动重生成覆盖。
43. 双击入口：无控制台时能启动；8765 被占用时顺延并打印实际地址。

## 八、残余风险

| 风险 | 说明 | 处理 |
|---|---|---|
| 名单顺序随 B | 名单内 A 的排序会被 B 的顺序取代 | 需求已确认；验收时抽查顺序是否可接受 |
| 固定项不用序号 | 顺序不同也能按编号对上，但要靠编号准 | 编号错就配不上，进问题清单，不会错搬 |
| B 与 A 项数不同但语义相同 | 例如 B 拆成两项 | 一律停下交人工，不自动合并 |
| 续表归属判错 | 把两张独立表当成一张 | 归属不明交人工；归属结论写进结构清单可复核 |
| 序号判错 | 识别把固定项当成名单项，或反过来 | 程序只校验矛盾：同一完整配对键下同侧多格 → 该表失败交人工，不会错搬；名单只有一项则放行 |
| 期间角色判错或漏标 | 把本期期初标成本期期末，或多套期间只标一套 | 同一完整配对键下同侧多格 → 该表失败交人工；该编号要求期间却标“未知” → 不配、记问题，不会错搬 |
| 期间写法不统一 | 一侧写“期末”、另一侧写“本期期末” | 规范要求只有一套期初期末时一律记“本期”；写法非法判失败 |
| 表认错 | 同科目下两张同名表被当成一张 | 同侧同名多张一律交人工，不按位置猜 |
| 列标题写不进去 | 列标题落在多级合并表头里 | 先写集成用例实测；写不进去时该表退回人工（标签与数字都保持原样），其他表不受影响 |
