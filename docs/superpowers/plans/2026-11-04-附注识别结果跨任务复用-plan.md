**目标。** A 按业务表组复用，B 优先复用可见底表布局，金额不参与复用身份；本次任务独立读值、配对、生成标题、写回和回读。采用本地记录文件和内存索引。

**依据。** [已确认需求](../../requirements/2026-11-04-附注识别结果跨任务复用-requirement.md) · [已修订设计](../specs/2026-11-04-附注识别结果跨任务复用-design.md)。程序依据为 [ecd71f0 仓库快照](https://github.com/quanfanpro-code/audit-notes-auto-carry/tree/ecd71f0149e01aa8a5bd8e8eb160b9b27721346e)。文件名以下均以该仓库根目录为起点。新文件注明“新增”。日后执行前先定位实际仓库、核对当时版本差异，并按全局规则备份、校验被修改的原件。

**执行方式。** Windows 原生 Python，复用现有表格读取、模型调用、配对和 Word 桥接。依次完成下列七个任务。未来获准编码后，每项先跑指定用例，确认它因目标行为缺失而失败，再做最小改动，并运行该项用例及受影响的既有测试。下列命令均从仓库根目录执行；PowerShell 中先设置 `$测试器='C:\Users\27651\AppData\Local\Programs\Python\Python314\python.exe'` 并核实路径。命令和预期结果是计划，不是已通过的测试。

## 任务四｜接入三遍复用、分步发布和任务续跑

- [ ] **先验证失败。** 新增 `测试/test_三遍复用.py`。同一服务连续运行三份相同布局，二、三份均命中。第一份 B “存货”因 A 缺科目跳过，第二份 A 有该科目：固定答复样本中 B 三遍调用应为 0、0、1。再测 A 删除中间科目、末尾表移位、续表不明和新旧混用。
- [ ] **接入识别。** 修改 `核心/识别.py` 三个调用点，而非在任务外复制一套流程。第一遍按整侧科目覆盖、第二遍按整侧分表覆盖判断，第三遍按主表和续表整组确定。回退时使用现有材料与校验；记录每侧每遍的真实调用次数、重试和每组回退原因。模型调用计数落在实际发送请求处（`核心/模型调用.py`），不能把读已有答复或打开索引计成调用。
- [ ] **接入任务和发布。** 在 `核心/流程.py` 的任务入口统一刷新索引，供同一服务进程的后续任务和直接调用共用。在锁内重验并登记使用关系，再把解释计入当前任务。上游布局在自身覆盖检查通过后分别取得发布资格；第三遍需在本组必需检查及适用配对检查后发布。跳过只阻止第三遍；若后续错误证实上游布局也错，停用其记录并追溯。部分任务失败，只接纳已独立通过检查且边界明确的记录。重新检验本侧覆盖、组内序号、漏段、重复键和完整性，`核心/比对.py` 仍依据本次检查决定清尾。相同任务续跑先校验原输入、金标准及规则版本；已有使用登记幂等，版本不明不复用旧中间结果。
- [ ] **复验。** `& $测试器 -m pytest -q 测试/test_三遍复用.py 测试/test_接续.py 测试/test_比对.py 测试/test_服务.py`。完整命中为 0、0、0；固定无重试的单物理表组需要三遍各跑一次时为 1、1、1。首次任务仍可在库关闭或不可用时完成正常识别。

- [ ] **拆开识别和写回。** 修改 `核心/识别.py` 让 A 输出定位、期间角色和替换规则；B 保留本次“期间实际”及其来源位置。修改 `核心/流程.py`，在两侧配对后，按本次搬运清单及组级保护结果确定哪些组本次需要搬运，并对这些组检查标题期间。入选取决于本次搬运资格，不按新旧金额是否不同或差异清单是否非空筛选。按 B 组、角色逐处归集唯一日期，再用 A 当前原文组装标题指令，调用 `核心/写回.py`。预检查失败时撤回该业务表组的标题与数值变更、记入问题清单，确保本次更新后的 Excel 与 Word 对同组使用同一结果。桥接阶段失败沿用原撤回路径。A 第二遍、旧标题新文、系统日期均不得提供目标日期。B 日期本身也不得取自旧记录。

## 任务六｜提供停用、裁决与影响查询的内部入口

- [ ] **实现入口。** 新增本机模块 `核心/复用管理.py`，在任务三的同一跨进程锁内提交事件。最小调用约定如下；本期不加 Web 写接口或 GUI。
