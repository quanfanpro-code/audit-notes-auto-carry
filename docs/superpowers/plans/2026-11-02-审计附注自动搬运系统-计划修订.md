## 二、全局数据约定变更

### 2.1 结构记录（每张物理表一条）

```python
结构记录 = {
    "侧": "A", "区域": "TA_008", "行范围": [56, 61],
    "科目": "货币资金", "表名": "余额构成",
    "表组": "TA_008",                 # 业务表组标识，续表填同一个值
    "续表序": None,                   # 续表写 2、3…；非续表为 None
    "列": [{"列": "B", "路径": "项目", "角色": "行名列", "期间": None},
           {"列": "C", "路径": "期末余额", "角色": "数据列", "期间": "期末", "序号": None}],
    "行": [{"行": 57, "名字": "库存现金", "角色": "数据", "分组": None, "序号": None,
            "槽位": {"C": "C-N087-T001-S001"}}],
    "作用范围": {"币种": "人民币", "单位": "元",
                 "期间角色": "期末", "期间实际": "2025-12-31", "期间跨度": "时点"},
    "空名单": [{"槽位": "C-N054-T003-S002", "说明": "本期无"}],
    "完整性": {"第一遍覆盖": True, "第二遍归段": True,
              "第三遍逐项": True, "空名单已声明": True},   # 程序判定后写入
    "原始结构": {"合并": [...]},
    "例外": [],
}
```

`序号` 的填法：

| 情况 | 怎么填 | 后续怎么用 |
|---|---|---|
| 固定项（本表这个编号只出现在一项里，如库存现金） | 留空 | 配对看编号；该编号要求期间时再加期间角色，两侧顺序不同也能对上；一项里可能有两格（期初、期末） |
| 名单项（甲债券、薪酬类别、账龄、资产类别） | 按出现先后填 1、2、3；排在列上就按列序 | 配对看编号＋序号；该编号要求期间时再加期间角色 |
| 汇总项 | 留空 | 按编号，再按分组；该编号要求期间时再加期间角色 |
| 识别失败的项 | **照样填序号**，只是它里面某些格的编号为空 | 保证后面的项不前移 |

一张表里名单只在行上或只在列上；两边都有 → 交人工。

`期间角色` 的填法：每个数据格填七种写法之一——本期期初、本期期末、上期期初、上期期末、本期发生、上期发生、未知，由识别按该格在项内的位置给。

- **同一项里可能有好几格共用一个编号**：`C-N049-T001-S001` 盖住期初和期末；`C-N087-T001-S001` 同样；`C-N067-T001-S317` 盖住本期期初、本期期末、上期期初、上期期末四格；`C-N095-T001-S103` 同时用于本期和上期发生额。靠期间角色分开。
- **表里只有一套期初／期末时一律记“本期”**，不写裸的“期初”“期末”，免得两侧写法长短不一配不上。
- **年份不填进这里**，换年照常更新。
- **“未知”不是证据**：该编号声明 `period` 必填时，任一侧是“未知”就不配、记问题、整项保留；没有 `period` 维度的编号不受影响。两侧各只有一格也不例外。

`表组` 标识规则：A 侧用区域名（`TA_008`）；B 侧用 `工作表!起始行`（如 `word附注!120`）。续表填表首那张的标识。**这个号只在各自一侧区分同名表，不能拿去和对面比**——两侧配对准用 `科目＋表名`。

**改什么**

### R4 比对：按编号（＋序号）（＋期间角色）配对、完整性消费、真实编号集合

**Files**：改 `核心/比对.py`、`测试/test_比对.py`

**算法（程序机械执行）**

1. **认表**：先按 `科目＋表名` 把 A、B 两侧的表对起来。同侧同名两张 → 该科目交人工。找不到对面 → 该组全部 `仅A侧有`/`仅B侧有`。
2. 组内口径检查：币种或金额单位两侧都有且不同 → 全组 `口径冲突`；期间角色或跨度不相容 → 全组 `口径冲突`；同类换年 → 不停，取 B 日期。
3. **比项数**：取两侧完整项清单的项数（含失败占位项）。B 多 → 全组 `需加项`、不产生变更；B 少 → 记下待清尾的尾部项；相等 → 正常。
4. **分桶，先查期间**：对每个编号先查 `期间必填(索引, 编号)`，再决定键里要不要带期间角色。
   - 要求期间：`序号` 为空且是汇总格 → `(槽位, 期间角色, 分组)`；`序号` 为空的其他格 → `(槽位, 期间角色)`；`序号` 有值 → `(槽位, 序号, 期间角色)`。
   - **不要求期间（没有 period 维度）**：`序号` 为空且是汇总格 → `(槽位, 分组)`；`序号` 为空的其他格 → `(槽位)`；`序号` 有值 → `(槽位, 序号)`。**键里不含期间角色**，原期间值照实保留在记录里，不改写、不删除。
   分桶直接用记录自带的值，**不从剩余记录重排**。
5. 桶内两侧各一格 → `对应`。
6. **“未知”不配对**：该编号 `期间必填` 为真时，期间角色为“未知”的格不进上面的桶，直接判 `期间角色未知`、整项保留；两侧各只有一格也一样。`期间必填` 为假时**既不拦“未知”，也不比较期间**——A 写“本期期末”、B 写“未知”，或两边写两个不同的已知期间，都照配。
7. 名单桶 A 有、B 无，且该序号属于第 3 步定下的尾部、且该组 `完整性` 四项全真 → `清尾`；完整性不成立 → `仅A侧有`。
8. 桶里 B 有、A 无 → 一律 `仅B侧有`，**不据此判 `需加项`**。是否加项只看第 3 步的项数比较。
9. **重复判断沿用第 4 步的完整配对键**：同一桶内同侧多格才判 `同侧重复`。汇总格的桶含 `分组`，所以两个分组的小计各配各的、不算重复；不同编号各一格（库存现金、银行存款）也不算重复。**不要求期间的编号，判重同样不看期间**：同侧两个 `C-N019-T013-S006` 一个写“本期期末”、一个写“本期期初”，其余条件相同，仍判重复，不能靠期间写法不同逃过去。
10. 编号为空或不在金标准编号集合 → `槽位编号缺失`。**删掉 `_合法()` 里的 `startswith("C-N")`**，改用 `编号存在()`。
11. 项标签格不参与桶配对，但仍进清单。未对应的每一格都要进清单。

**必须先失败的用例**

| 用例 | 断言 |
|---|---|
| `test_固定编号顺序相反仍对应` | 库存现金、银行存款两侧顺序相反，各自对应 |

### R5 搬运：项标签随项、同进同退、清尾落地

**Files**：改 `核心/搬运.py`、`测试/test_搬运.py`

**规则**

1. 名单项按 `表组＋序号` 分组；固定项按 `表组＋编号`。该编号要求期间时键里再加期间角色，不要求期间时**不加**（否则同一固定项的期间写法两边不同就搬不动）。该组所有应搬格状态必须是 `对应`；任一格 `未对应`／`槽位编号缺失`／读取失败 → 整项不动，问题清单记原因。
2. `清尾` 项：项标签与所有数据格写空，问题清单记“B 无此项，已清空”。
3. 项标签搬不搬：名单项的标签取 B 同组同序号（行上写回行标，列上写回列标题）；固定项与汇总项不写。**写列标题失败时，整项数字也不写**，标签与数字都保持 A 原样，问题清单记“列标题写入失败，整项退回人工”。
4. 汇总格取 B 原值，程序不重算。
5. 项标签与数据同批提交，不分开写。

**必须先失败的用例**

| 用例 | 断言 |
|---|---|
| `test_项标签随项搬` | 名单行 B 写乙债券 → A 该行行标变乙债券，金额同变 |
| `test_列标题随列搬` | 名单列 B 写专用设备 → A 该列列标题变专用设备，数字同变 |
| `test_列标题写失败整项不写` | 模拟列标题写入失败 → 该列标签与数字都保持 A 原值，问题清单有记录 |
