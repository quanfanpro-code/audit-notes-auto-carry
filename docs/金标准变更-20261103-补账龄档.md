# 金标准变更记录：补账龄档与坏账准备列（2026-11-03）

## 一、为什么要改

真实验收（天宇油脂 2025 年附注）走到应收账款账龄表时卡住，原因不在程序，在金标准缺号：

1. 附注的账龄分档是「1-3个月／4-12个月／1-2年／2-3年／3年以上」，金标准只建到「1年以内／1至2年／…」，前两档没有任何编号。
2. 这张表有「期末坏账准备／期初坏账准备」两列，金标准「按账龄披露」只建了「账面余额」列，坏账准备列整列无号。

当时的临时办法是前两档共用一个「1年以内」编号、靠序号区分，坏账准备列标「不搬」交人工。前者靠两侧顺序一致才不出错，后者一次留下 8 个空格。都不是长久办法。

## 第二批：账龄组合两表组补期初与比例列（同日）

### 为什么再补

做完应收账款前五张表，第六张「按账龄组合计提坏账准备」对不上号。核了原表与标准，缺三样：

1. **期初三列整列没有编号**。原表有「期初·账面余额·金额／比例(%)／坏账准备」，标准该组 28 条里只有「期末余额」下的列，期初一条都没有。今年附注的“期初”就是去年的“期末”，滚下一年必须跟着换，不能不管。
2. **细分两档没有编号**。原表把“1年以内”拆成「3个月以内（含3月）」「4-12月（含12月）」，标准第一档只有 0–1 年一个编号，两行只能靠行序区分；另外原表「3年以上」是开口档（3 年以上到无穷），标准只有 3–4、4–5、5 年以上三个细分档，没有这个开口档。
3. **“比例(%)”这一列没有槽位**。原表把“账面余额”拆成“金额／比例(%)”，比例是各账龄段占总额的比重（79.97 + 20.03 = 100）；标准里同位置叫“计提比例(%)”，是坏账准备÷账面余额（该行实际 0.5%），语义不同，不能套用。

### 补了什么

两个表组各 30 条，合计 **60 条**；只追加，不改旧条目。条目总数 12,853 → 12,913。

以「应收账款／按账龄组合计提坏账准备」为例（其他应收款同构，编号整体不同）：

| 编号 | 槽位 | 账龄边界 | 期间 |
|---|---|---|---|
| S041 / S042 | 3个月以内 / 期末余额 / 账面余额、坏账准备 | 0–0.25 | 期末 |
| S043 / S044 | 4-12个月 / 期末余额 / 账面余额、坏账准备 | 0.25–1 | 期末 |
| S045 / S046 | 3年以上 / 期末余额 / 账面余额、坏账准备 | 3–∞ | 期末 |
| S047–S051 | 期末余额 / 账面余额 / 比例(%)，五个档 | 各档 | 期末 |
| S052 | 期末余额 / 账面余额 / 比例(%)，合计 | — | 期末 |
| S053–S057 / S058 | 期初余额 / 账面余额，五档＋合计 | 各档 | 期初 |
| S059–S063 / S064 | 期初余额 / 账面余额 / 比例(%)，五档＋合计 | 各档 | 期初 |

「1至2年」「2至3年」两档原本就有（S031/S032、S033/S034），本次不重复建。

## 第三批：坏账分类表整组并归（同日）

### 问题

「应收账款／按坏账计提方法分类披露」这一组 284 条，同一个意思有 **29 种写法**：按单项计提坏账准备、按单项计提坏账准备的应收账款、按单项计提坏、单项计提、`<坏账计提方法>`，以及被截断的「按信用风险特」「征组合」「账准备的应收账款」等。列上还有「比例」与「比例(%)」、「计提比例」与「计提比例(%)」两套写法。

后果：同一行在不同公司表里取到不同编号，A、B 两侧对不上；缺口也没法补，因为不知道该补到哪个名字下。

### 怎么并的

按来源原文＋列结构判断归属，归成 8 个规范行：

| 规范行 | 收了哪些写法 |
|---|---|
| 按单项计提坏账准备 | 本名、按单项计提坏账准备的应收账款、按单项计提坏、单项计提、`<坏账计提方法>`、按单项计提坏账准备/单项计提 |
| 单项金额重大并单独计提坏账准备的应收账款 | 本名、单项金额重大、两种嵌套写法 |
| 单项金额不重大但单独计提坏账准备的应收账款 | 本名、单项金额不重大、两种嵌套写法 |
| 按组合计提坏账准备 | 本名、按组合计提坏账准备的应收账款 |
| 按账龄组合计提坏账准备 | 本名、按账龄组合计提、账龄组合、三种嵌套写法 |
| 风险组合 | 本名、按组合计提坏账准备/风险组合、按信用风险特、征组合、按组合计提坏账准备的应收账款/按信用风险特征组合 |
| 无风险组合 | 新建 |
| 合计 | 本名 |

同义列一并收：「比例」并入「比例(%)」，「计提比例」并入「计提比例(%)」。
