# 运行目录文件为权威产物，不引入数据库

系统全部阶段产物（合集、对应清单、A′、Excel/Word 新副本、回读记录、准确接续索引）以运行目录中的文件为权威数据，WebUI 与任务状态都读写这些文件；不引入 SQLite 等数据库作为事实来源。原因：需求约定的可追溯产物本身就是文件形态（调用留证、备份哈希、断点续接），文件进出便于逐项验收和按备份规则保护，且与旧项目可复用的合集/回执格式兼容；单机单用户的未对应清单查询用不着数据库。选文件是因为贴合现有成果形态与验收约定、改动更少，并非数据库做不到备份（SQLite 有官方备份机制 sqlite.org/backup.html）。考虑过 SQLite 中心方案：查询方便，但与现有文件形态成果、备份哈希及接续约定不一致，要另做导出层，故拒绝。
