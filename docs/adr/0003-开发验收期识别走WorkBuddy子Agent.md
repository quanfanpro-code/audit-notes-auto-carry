# 开发与验收期识别走 WorkBuddy 子 Agent（DeepSeek V4.1 Flash 1017）

用户暂不配置内置 API。开发与验收期 A、B 的真实识别由编排会话派遣 WorkBuddy 子 Agent 承担，模型固定 DeepSeek V4.1 Flash 1017（明确不用编排者本人模型）；程序按"委托识别＋答复导入"接入：材料与指令照常组装并留证（提示词守卫、材料完整规则不变），子 Agent 产出逐格身份 JSON 答复，程序按既有答复导入，断点复用与调用克制照旧。HTTP API（OpenAI 兼容）保留为运行期可选项，不因本决定删除。考虑过让识别程序直接调用模型 API：用户暂不配置凭据，且明确要求经 WorkBuddy 子 Agent 执行；考虑过编排者亲自识别：用户明确要求不用当前模型。

**2026-11-02 修订（本决定已被取代）：** 用户改为要求由编排会话本人（当前模型）执行真实识别，不派子 Agent、严格线性。程序仍按委托识别＋答复导入接入（每份材料留证，答复写入同目录 答复.txt）。代价：单会话上下文有限，天宇油脂 A 侧 66 张表、B 侧数十张表需按科目分批推进，或改配 API 由程序自动跑。
